# 🫁 HI-PEITHO — 中危 PE 的導管導向溶栓

## [Rosenfield K, et al. *N Engl J Med* 2026 (HI-PEITHO)](https://doi.org/10.1056/NEJMoa2516567)

| 項目 | 內容 |
|------|------|
| 設計 | 多國 adaptive RCT，盲性判讀；n=544 |
| 族群 | 中危 PE：RV/LV ≥1.0 + troponin↑ + ≥2 心肺窘迫指標 |
| 介入 | USCDT（EkoSonic + alteplase）+ 抗凝 vs 單純抗凝 |
| 主要終點(7d) | **4.0% vs 10.3%，RR 0.39 (0.20–0.77)，P=0.005**；NNT≈16 |
| 安全 | 大出血 4.1% vs 2.2%（NS）；**無顱內出血** |

> 由「心肺失代償/休克」下降驅動 → 中危 PE 介入有臨床淨效益。

# 🫀 BioVAT-HF — 幹細胞工程心肌組織移植

## [Zimmermann WH, et al. *N Engl J Med* 2026 (BioVAT-HF)](https://doi.org/10.1056/NEJMoa2513525)

| 項目 | 內容 |
|------|------|
| 設計 | Open-label phase 1–2；n=20；iPSC 衍生工程心肌心外膜移植 + 免疫抑制 |
| 族群 | HFrEF，LVEF ≤35% + ≥1 hypokinetic/dyskinetic 節段 |

# 💔 ALLEVIATE-HF — 監測≠改善預後

## [Butler J, et al. *J Am Coll Cardiol* 2026 (ALLEVIATE-HF)](https://doi.org/10.1016/j.jacc.2026.03.075)

| 項目 | 內容 |
|------|------|
| 設計 | RCT；n=711；ICM (Reveal LINQ) + HF 風險軟體 |
| 介入 | 高風險警示 → 護理師主導個人化利尿 vs 標準照護 |
| 主要安全 | 介入相關 SAE 0.32%（≤5% 門檻）→ **安全** |
| 主要療效 | win ratio **0.79 (0.62–1.01)，P=0.06 → 未達標** |
| 安全信號 | CV death+HF 事件 **HR 1.43 (0.95–2.15), P=0.091** |

> ⚠️ 本週「what didn't work」：監測 + 加強利尿直覺合理，實測 **neutral 且帶 harm signal**——策略需 RCT 驗證，不可理論外推。

# 🎓 本週 5 大臨床啟示

1. **PFA 療效是真的** — PFA-SHAM 以假手術證明 PFA 降低 AF 復發/負荷、改善生活品質，非安慰劑效應。
2. **中危 PE 介入有淨效益** — HI-PEITHO：USCDT 7 天複合終點降 61%、不增加大出血、NNT≈16；但仍須嚴選病人。
3. **監測 ≠ 改善預後** — ALLEVIATE-HF：ICM 風險導引利尿介入 neutral 且帶 harm signal，策略需 RCT 驗證。
4. **再生醫學進入臨床門檻** — BioVAT-HF 工程心肌移植首見人體正向訊號，但安全性與長期效益待解。
5. **"One-and-done" 降脂成形中** — VERVE-102 單次 base editing 達持久 LDL ↓62%；Lp(a) 路線（obicetrapib/evolocumab）同步推進。
