## 1. 本週重點摘要 (Top 5 Picks)

| # | 試驗 / 主題 | 期刊 | 結果方向 | 一句話總結 |
|---|------------|------|---------|-----------|

## 2. 🫀 TAVI Section

### 2.1 NOTION-3 子分析 — Angina 對 TAVI 病人 PCI 預後的影響

[PMID 42189952](https://pubmed.ncbi.nlm.nih.gov/42189952/) ｜ Circulation 2026

| 項目 | 內容 |
|------|------|
| 背景 | NOTION-3 主試驗已證實 TAVI 合併穩定型 CAD 病人，**完整 PCI** 相較單純藥物治療可降低複合心血管事件 |
| 本次分析 | 探討 baseline **angina（心絞痛）狀態**是否改變 PCI 的治療效益方向 |
| 臨床意義 | 協助釐清「無症狀 CAD 的 TAVI 病人是否仍應 PCI」——是 TAVI + CAD 處置決策的關鍵問題 |
| Take home | TAVI 病人的 CAD 處置應整合「症狀 + 解剖 + 缺血」，而非一律 revascularize |

### 2.2 純主動脈瓣逆流 (pure AR) TAVR 的瓣葉穿孔 — Annulo-Aortic Angulation 的重要性

[PMID 42191329](https://pubmed.ncbi.nlm.nih.gov/42191329/) ｜ JACC Cardiovasc Interv 2026

- **Pure AR 行 TAVR（off-label）** 本就因缺乏鈣化錨定而困難；本短篇點出 **annulo-aortic angulation（環口-主動脈夾角）過大**會增加部署時 transcatheter valve 的瓣葉受力與穿孔風險。
- 對 Drake 的臨床意義：**水平心 / 大夾角 + pure AR** 的個案，pre-procedure CT 應特別評估夾角並據以選瓣與調整部署策略。

### 2.3 TAVR vs SAVR at 7 Years — NEJM 讀者來函系列

[PMID 42202336](https://pubmed.ncbi.nlm.nih.gov/42202336/)（及多篇回覆 [42202337](https://pubmed.ncbi.nlm.nih.gov/42202337/) / [42202335](https://pubmed.ncbi.nlm.nih.gov/42202335/) / [42202334](https://pubmed.ncbi.nlm.nih.gov/42202334/) / [42202333](https://pubmed.ncbi.nlm.nih.gov/42202333/)）｜ NEJM 2026

- 圍繞低風險 TAVR vs SAVR **7 年長期結果**的多篇讀者來函與作者回覆（Leon, Mack, Pibarot 等回覆），延續低風險族群「長期耐久度與結構瓣膜衰退」的辯論。
- 重點不在單一數據，而在提醒：**低風險年輕病人選 TAVR 仍須把 7–10 年耐久度納入 shared decision-making**。

## 3. 🔧 TEER / 三尖瓣介入 Section

> **本週說明**：本週**無新的 mitral / tricuspid TEER 隨機試驗或大型登錄**；以下為與 edge-to-edge / 三尖瓣經導管治療相關的併發症與技術 case reports。

### 3.1 三尖瓣 TEER 裝置卡在右心室 pacing lead 上 (Device Entrapment)

[PMID 42191326](https://pubmed.ncbi.nlm.nih.gov/42191326/) ｜ JACC Cardiovasc Interv 2026

- **Tricuspid TEER 的特殊併發症**：clip / 裝置在右心室側與既有 **RV pacing lead** 纏繞卡住。
- 教學點：tricuspid TEER 術前須注意既有 CIED lead 的走向；grasp 前以影像確認 lead 與瓣葉、夾合區的關係，避免 entrapment。

### 3.2 Heterotopic Bicaval Valve-in-Valve 處理晚期血栓

[PMID 42191325](https://pubmed.ncbi.nlm.nih.gov/42191325/) ｜ JACC Cardiovasc Interv 2026

- 三尖瓣 / 腔靜脈經導管治療後 **late thrombosis** 的 bailout：以 heterotopic bicaval ViV 處理。
- 提醒三尖瓣 / CAVI 治療後仍須留意瓣膜血栓，並保留 ViV 作為 rescue 選項。

## 6. 各期刊概況

### NEJM（本週心血管含量高）
本週 NEJM 心血管極為精彩：再生醫學的 **BioVAT-HF**（工程心肌組織）、基因編輯的 **VERVE-102**（PCSK9 base editing）、與介入的 **HI-PEITHO**（中危 PE 導管溶栓）同期登場，並有兩篇再生醫學社論（Srivastava「Remuscularizing the Failing Human Heart」、Margulies「Patching Up Damaged Hearts」）。另有 TAVR vs SAVR 7 年讀者來函系列、二級中風預防、心血管危險因子（高血壓/生活型態）教育文章。

> 註：HI-PEITHO、BioVAT-HF、VERVE-102 三篇 Drake 已另有獨立深入講義，本週報以「本週 NEJM 焦點」角度收錄。

### 2.x 詳述 — Top 5 補充資料

#### PFA-SHAM（Circulation；PMID 42186803）

| 項目 | 內容 |
|------|------|
| 設計 | 前瞻、**sham-controlled、單盲、終點盲性判讀**的隨機試驗；n=60，1:1 分配 PFA vs 假手術；全員植入 ICM 連續監測 |
| 族群 | 高度症狀性 AF（AFEQT < 50），paroxysmal 或 persistent |
| 主要終點(6mo) | (1) 首次房性心律不整復發；(2) AFEQT 生活品質變化 |
| 結果 | 復發 **6.7% (PFA) vs 83.3% (sham)**，posterior HR **19.6** (95% BCI 6.7–76.9)；AFEQT 改善 +43.9 vs +11.3（差 32.6）；AF burden、HADS 焦慮憂鬱分數皆顯著優於 sham |
| 結論 | PFA 在降低復發/負荷、改善生活品質與心理困擾上**全面優於假手術** → 療效非安慰劑效應 |
| 限制 | 樣本小 (n=60)、追蹤短（withholding 治療給高症狀病人的倫理考量） |

#### HI-PEITHO（NEJM；PMID 41910345，NCT04790370）

| 項目 | 內容 |
|------|------|
| 設計 | 多國、adaptive-design、盲性終點判讀 RCT；n=544（介入 273 / 對照 271） |
| 族群 | **中危 PE**：RV/LV ≥ 1.0 + troponin↑ + ≥2 項心肺窘迫指標 (SBP ≤110、HR ≥100、RR >20) |
| 介入 | 超音波輔助導管導向溶栓 (EkoSonic + alteplase) + 抗凝 **vs** 單純抗凝 |
| 主要終點(7d) | PE 相關死亡 / 心肺失代償或休克 / 症狀性 PE 復發之複合 |
| 結果 | **4.0% vs 10.3%**，RR **0.39** (95% CI 0.20–0.77)，**P=0.005**；主要由「心肺失代償/休克」下降驅動；NNT≈16 |
| 安全性 | 7 天大出血 4.1% vs 2.2%（NS）、30 天 4.1% vs 3.0%（NS）、**無顱內出血** |
| 結論 | 中危 PE 用 USCDT 有臨床淨效益，且不顯著增加大出血 |

#### ALLEVIATE-HF（JACC；PMID 42201288，NCT04452149）

| 項目 | 內容 |
|------|------|
| 設計 | RCT；n=711（介入 357 / 觀察 354）；Reveal LINQ ICM + 投資性 HF 風險軟體 |
| 介入 | 高風險警示 → 中央協調、護理師主導、個人化 protocol 利尿介入 **vs** 標準照護 |
| 主要安全 | 介入相關 SAE **0.32%**（遠低於 ≤5% 門檻）→ 安全 |
| 主要療效 | 5 成分階層複合（CV death/HF 住院/門診 HF 事件 + KCCQ + 6MWD），win ratio **0.79** (95% CI 0.62–1.01)，**P=0.06 → 未達標** |
| 安全信號 | CV death + HF 事件數值上**更高**：HR **1.43** (95% CI 0.95–2.15, P=0.091) |
| 結論 | 安全但對主要結果 **neutral**；另發現此族群「臨床上重要的心律不整負荷被低估」 |

> ⚠️ **負向試驗的教學價值**：ALLEVIATE-HF 是本週最值得討論的「what didn't work」。「裝置監測 + 加強利尿」直覺上應有益，但實測 neutral 且帶 harm signal，提醒我們**監測≠改善預後**，介入策略需 RCT 驗證而非理論外推。

#### BioVAT-HF（NEJM；PMID 42202318，NCT04396899）

| 項目 | 內容 |
|------|------|
| 設計 | Open-label phase 1–2；n=20；同種異體 iPSC 衍生工程心肌 (5/10/20 units) 心外膜移植；全員免疫抑制 |
| 族群 | HFrEF，LVEF ≤ 35% + ≥1 段 hypokinetic/dyskinetic 節段 |
| 結果(3mo, 安全最大劑量 20 units, n=12 完成) | 目標心壁增厚 **+4.5 mm** (P<0.001)、LVEF **+3.9%** (P=0.04)、KCCQ-OSS +6.7 (P=0.06, NS) |
| 安全性 | 3 例死亡（vasoplegia / COVID-19 / aortic dissection）、1 例心臟移植、4 例停免疫抑制；**全數至少 1 個 AE** |
| 結論 | 工程心肌「再肌肉化」的首次人體訊號正向，但屬早期、需更長追蹤 |

#### VERVE-102（NEJM；PMID 42187087，NCT06164730）

| 項目 | 內容 |
|------|------|
| 設計 | Phase 1、open-label、單次劑量遞增；n=35；單次 IV，劑量 0.3–1.0 mg/kg total RNA（adenine base editor mRNA + guide RNA，LNP + GalNAc） |
| 族群 | HeFH 或早發 CAD 成人 |
| 結果 | PCSK9 ↓51%（0.3）→ **88%（1.0 mg/kg）**；LDL-C ↓9% → **62%（−78 mg/dL）**；效果持久，15 人追蹤 ≥1 年仍維持 |
| 安全性 | 無 dose-limiting toxicity；輕中度 infusion 反應、暫時性 ALT↑；1 例 GERD 病人吸入性肺炎 |
| 結論 | 單次 in vivo 鹼基編輯可達持久、實質的 PCSK9/LDL 下降——"one-and-done" 降脂的概念驗證 |
