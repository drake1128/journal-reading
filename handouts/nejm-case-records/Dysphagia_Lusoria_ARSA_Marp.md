# Dysphagia Lusoria
## 異常右鎖骨下動脈壓迫食道

# 病例 (Case)

- **44 歲男性**，腦性麻痺；**4 年進食嗆咳**
- 曾治逆流（PPI）+ 食物質地調整，**症狀持續**
- **內視鏡**：上段食道後壁**搏動性、條索狀**結構壓迫
- **CT**：**異常右鎖骨下動脈 (ARSA)**，主動脈弓第 4 分支，走行**食道後方**

> 診斷：**Dysphagia lusoria**。

---

# 什麼是 Dysphagia Lusoria

- **ARSA / arteria lusoria**：最常見先天主動脈弓分支異常（~0.5–2%）
- 為弓部**最後一支**、起點在左鎖骨下遠端，**~80% 走行食道後方** → 壓迫
- 多數**無症狀**；有症狀才稱 dysphagia lusoria
- **中年才發病**：血管**硬化/延長**後壓迫加劇

> 成人新發、進行性吞嚥困難 + 食道後壁搏動壓迫 → 想到血管性病因。

---

# 診斷工具

| 工具 | 典型發現 |
|------|----------|
| Barium swallow | 食道後壁斜向**壓痕** |
| CT / CTA | ARSA 走行、有無 **Kommerell 憩室** |
| 內視鏡 | 黏膜外**搏動性**壓迫（勿誤為可切腫瘤）|

---

# 處置與心臟科須知

- **輕度** → 保守（飲食調整、吞嚥/語言治療）— 本例 3 個月改善
- **嚴重/難治** → 外科：ARSA **離斷 + 再植**
- 心血管須知：
  - **Kommerell 憩室** → 破裂/剝離風險，需追蹤
  - **非返喉神經** → 頸部/甲狀腺手術神經走行異常，易受傷

---

# Take-home

> **1.** 成人進行性吞嚥困難 + 食道後壁搏動性壓迫 → **dysphagia lusoria (ARSA)**。

> **2.** 最常見弓部分支異常；中年血管硬化後才出症狀。

> **3.** 輕度保守、嚴重外科離斷再植。

> **4.** 留意 **Kommerell 憩室**與**非返喉神經**。
