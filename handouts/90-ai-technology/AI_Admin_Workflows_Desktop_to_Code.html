What is it

Claude 是什麼？一個隨叫隨到的助理

把它想成一位讀很多書、打字很快、24 小時待命的助理。你只要做三件事：

🗣️

① 問它

問問題、要草稿、想點子、請它解釋。

📎

② 給它資料

貼上文字，或上傳 Word／Excel／PDF 讓它讀。

📤

③ 要產出

請它給你信、表格、摘要、公式、模板。

關鍵心態不必一次到位。先丟出去、再追加要求 —— 跟交代真人助理一模一樣。

06
Golden rule

黃金法則：把它當成新進助理

講不清楚，它就做不好。一句好指令（prompt）有三要素：

  • 角色：你是一位資深祕書／護理長…
  • 任務：幫我把這段話寫成正式通知
  • 格式：用三段、條列、正式語氣、200 字內
加分技巧給範例、給資料、請它先確認再做。
範例 Prompt 你是醫院祕書。幫我把下面這段口語，
改寫成給全科同仁的正式 Email 通知，
語氣客氣、條列重點、100 字內，
最後附一行回覆期限。

「下週三下午兩點科務會議改到會議室B，
請大家準時，順便交季報。」

First step

第一步：打開 Claude Desktop

1下載安裝 Claude Desktop（或直接用網頁 claude.ai）
2用公司／個人帳號登入
3認識畫面：輸入框、＋上傳、新對話、歷史紀錄
4在輸入框打字交代任務，按 Enter
🆕

一任務一對話

不同的事開新對話，思緒不打架、回答更準。

📎

善用上傳

把 Word／Excel／PDF 直接拖進去，它就能讀。

Workflow ① · Email

✉️ Email 撰寫與回覆

  • 起草：給幾個重點 → 完整的中／英文信
  • 潤稿：把草稿改得更客氣／更簡潔／更專業
  • 長信摘要：貼上長信 → 三行重點 + 建議怎麼回
  • 中英互譯：回覆國外廠商、論文通訊
你給的（口語）跟廠商說下週的 demo 要改期，問他們三月初哪天方便。
它產出（英文正式信）Dear … We would like to reschedule next week's demo. Could you let us know your availability in early March? …
小提醒寄出前自己讀一遍，確認語氣與事實 —— 它是助理，不是主管。
謝慕揚 MD, PhD, FESC
10
Workflow ② · Meeting

📝 會議記錄與逐字稿整理

  • 把逐字稿或筆記貼進去（或先用手機錄音轉文字）
  • 請它整理成：議題 → 討論 → 決議 → 待辦
  • 待辦自動標上負責人與期限
  • 太長？再要一份一頁摘要給沒到的人
範例 Prompt 你是會議祕書。把下面這份逐字稿，
整理成正式會議記錄：
① 出席　② 各議題的決議
③ 待辦事項表（事項／負責人／期限）
最後加一段 三行摘要。

〔貼上逐字稿…〕

Workflow ③ · Excel

📊 Excel 資料整理

  • 清理：日期／單位格式不一 → 一鍵統一
  • 找公式：「我要算每月加總／達成率」→ 給你公式並解釋
  • 分析：建議樞紐分析、找出異常值與重複
  • 班表：給條件 → 產生值班表草稿
🧮

不會公式也行

用白話描述要算什麼，它把 Excel 公式寫好給你貼上。

📈

看懂一堆數字

上傳表格 → 「幫我找出本月重點與異常」。

進階預告幾十份檔要一起處理？這正是 Claude Code 的強項（稍後 Part 3）。

Workflow ④ · Word

📄 Word 公文、報告與模板

  • 給要點 → 產出公文／簽呈／活動報告草稿
  • 改寫：把這段改得更精簡／更正式／更白話
  • 產生可重複套用的表單與模板（同意書、通知、檢核表）
  • 長文件 → 大綱與摘要，再逐段展開
範例 Prompt 幫我擬一份請示公文：
主旨：申請科內購置一台超音波機。
說明：① 現況　② 需求理由　③ 預算
正式公文格式、條列、語氣得體。

What is Code

Claude Code：會動手做的 AI

  • 能直接讀寫你電腦資料夾裡的檔案
  • 在一個輸入框，用中文交代任務就好 —— 不必寫程式
  • 能批次、重複、自動地把事情做完
🛡️

安全感是內建的

它每個動作前會先問你「可以嗎？」，你按同意它才動手 —— 不會偷偷改你的檔。

別被「終端機」嚇到那個黑底視窗，其實就是一個「打字交代任務」的對話框而已。
謝慕揚 MD, PhD, FESC

Getting started

Claude Code：第一次啟動

1安裝一次（桌面版，或請 IT／我幫你裝）
2在你的工作資料夾裡開啟
3用中文打一句任務，按 Enter
4它提議做法 → 你按同意 → 完成
你只要打這樣一句 請把這個資料夾裡所有 Word 檔轉成 PDF，
檔名保持一樣，放到一個新的 PDF 子資料夾。

⚠ 最重要

🔒 資料安全與病人隱私 (PHI)

🚫 絕對不要丟給雲端 AI姓名、病歷號、身分證、生日、聯絡方式、含病人資訊的影像／報告 —— 任何可識別個人的資料。
✅ 可以放心使用已去識別化的資料、純行政文件（公文、班表、會議記錄、衛教單張）、公開文獻與課本內容。
  • 三原則：去識別化、最小揭露、遵循院內資安政策
  • 不確定能不能丟？—— 先問、別猜
紅線一句話先去識別化，再上傳。涉及病人的判斷，永遠由你負責。
謝慕揚 MD, PhD, FESC

Make it a habit

把 AI 變成你的工作流程

1挑一件每週都要做、又煩的小事
2試一次；不滿意就追加指令（迭代）
3把好用的 prompt 存成你的範本
4量大又重複 → 升級到 Code
一個月後你會有一套屬於自己的「AI 行政 SOP」與 prompt 範本庫，越用越省力。
