1背景：AGENT DCB 是什麼

裝置概念

  • 「No Metal Left Behind」局部給藥：短時間（<60 秒）將抗增生藥物送入血管壁，不留下永久金屬或聚合物。
  • 藥物：紫杉醇 Paclitaxel 2 µg/mm²（低劑量）。
  • 賦形劑：Acetyl Tri-Butyl Citrate（ATBC，又稱 TransPax 塗層），維持塗層完整並促進藥物轉移。
  • 理論優勢：無多餘金屬層 → 降低晚期支架血栓、可保留側枝、利於日後再處理。

AGENT vs 對照 DCB（SeQuent Please）

重點：AGENT 用更低的藥量挑戰「不輸給」更高藥量的標準 DCB——這是所有試驗的共同主張。

2資料一：AGENT ISR 歐洲 RCT

EuroIntervention 2020;16:e328–e334（Hamm CW 等）｜NCT02151812

試驗設計

  • 多中心、隨機、開放標籤、非劣性試驗；歐洲（德、法）11 個中心。
  • 125 人，1:1 → AGENT n=65 vs SeQuent Please n=60。
  • 對象：先前以 BMS/DES 治療後發生 ISR；病灶 ≤28 mm、血管直徑 2.0–3.5 mm。
  • 平均年齡 68 歲、女性約 18%、糖尿病 37%。
  • 主要終點：6 個月 in-stent 晚期管腔流失（LLL），由獨立盲性 QCA 判讀；非劣性界值 0.20 mm。
  • 隨機前須以一般氣球成功預擴張；依 protocol 不允許切割氣球／旋磨等輔助工具（與真實世界不同，見討論段）。

結論：AGENT Japan SV 是第一個頭對頭比較兩種「不同紫杉醇配方」DCB 的小血管 RCT。低藥量 AGENT（2 µg）在 6 個月 TLF 非劣於 SeQuent（3 µg）——支持 AGENT 同時用於 de novo 小血管與 ISR。

4資料三：台灣／APAC 華人 All-comers 登錄

前瞻、觀察性、單臂、開放標籤、多中心、all-comers（de novo + ISR）登錄｜Tse-Min Lu 等。台灣 7 + 香港 1 + 新加坡 1 中心。

設計與族群

  • N=500 連續病人（ISR 302 ／ de novo 194，4 例未分類）；588 處病灶。
  • 主要終點：1 年 MACE（心因性死亡 + 心肌梗塞 + 標的血管再介入 TVR）。
  • 追蹤：30 天、6、12 個月，之後每年至 3 年。
  • 造影追蹤：計畫在第 9 個月，對 de novo 小血管 ≤2.5 mm 及前 100 例 ISR 執行。
  • 族群偏複雜：糖尿病 58%、基線狹窄 83%（嚴重）、華人 90%。

★帶領討論主軸：病灶準備 → 預防剝離 → 避免 Bailout → 維持 DCB

你的三個討論點串成一條臨床邏輯線。以下是帶討論的腳本與可丟出的數據錨點。

① 如何做「病灶準備（Lesion Preparation）」

DCB 沒有支架的支撐力，成敗幾乎取決於預擴張。準備目標：殘餘狹窄 <30%、無限制血流的剝離、TIMI 3 血流。

  • 工具階梯：semi-/non-compliant balloon → scoring／cutting balloon → 鈣化重時考慮 IVL（震波）或旋磨 rotablation。
  • 比例與壓力：氣球/動脈比約 1.0（登錄即 1.0±0.1）；採「充分但不過度」擴張，避免地理性遺漏。
  • 判讀：預擴張後若殘餘狹窄高或出現限制血流剝離，才考慮改策略——而非一開始就放支架。

📌 數據錨點：登錄整體技術成功 93.8%，但 de novo 僅 86.1% → 困難的 de novo 病灶最需要好的準備。

② Cutting／Scoring Balloon 預防嚴重剝離（Dissection）

切割／刻痕氣球能在較低壓力下產生「受控的微切割」，使擴張更均勻、減少不可控的螺旋狀剝離與彈性回縮——尤其在鈣化、纖維化、ISR 與分岔病灶。

  • 目標：把「限制血流的剝離（type ≥C/D）」壓下來，因為那才是被迫置放支架的主因。
  • 登錄對照：de novo 剝離 7.3% vs ISR 0.3%；de novo bailout 支架 7.0%。→ de novo 是「準備不足 → 剝離 → bailout」的高風險族群。
可丟出的討論張力（已核對原文）：AGENT ISR 歐洲 RCT 的 protocol 規定——「普通（未塗藥）氣球的預擴張是必須的」，但「rotablation、雷射斑塊切除、切割氣球、其他 DCB」等輔助工具在標的血管內「不被允許」（EuroIntervention 2020;16:e329, Interventional procedure 節原文）。也就是說，試驗刻意排除了 cutting balloon；但真實世界 all-comers 卻常常需要它。「試驗的乾淨條件」vs「臨床的複雜病灶」該如何拿捏？這是很好的 panel 辯點。

③ 避免 Bailout 支架 → 維持「不留金屬」DCB 策略

一旦因剝離被迫 bailout stenting，就等於把金屬放回去，違背 DCB 初衷，也失去 de novo 的正向重塑好處。

  • 登錄整體 bailout 僅 7.3% → 代表 92.7% 維持純 DCB。把這個比例守住，就是病灶準備的價值。
  • 守住純 DCB 的回報：de novo 37% 晚期管腔擴大（正向重塑）、無永久聚合物、利於日後再處理、極低支架血栓（0.2%）。

🔗 延伸（若時間夠可帶到）：事件率被「例行造影」高估（TVR 26.9% vs 4.9%）。臨床驅動追蹤下 MACE 僅約 5%——好的準備 + 合理的追蹤策略，能讓 DCB 的真實表現被正確呈現。

一句收斂（帶討論用）：「DCB 的成功不在那顆氣球，而在放氣球之前——把病灶準備好、用 cutting balloon 控制剝離、避免被迫補支架，才能真正留住『不留金屬』的長期好處。」

6可能被問到的問題（答案已附）

以下答案直接顯示，方便上台前複習或現場分享。

DCB 後出現剝離，什麼程度一定要放支架？
原則是「限制血流／威脅閉合」才放：NHLBI type ≥ C–F、TIMI 血流下降、或長段／螺旋狀剝離。非限制血流的 type A–C 多可保守處理（延長充氣、必要時 spot stent），不必整段支架化。
Cutting balloon 會不會增加穿孔風險？怎麼選工具？
在嚴重鈣化使用高壓切割確有穿孔疑慮；策略是依鈣化程度分流——纖維／中度用 scoring/cutting，重度環狀鈣化優先 IVL 震波或旋磨先「改質」，再用 DCB。重點是低壓、適當尺寸、影像（IVUS/OCT）輔助判斷。
那 AGENT ISR 試驗本身怎麼做病灶準備？可以用 cutting balloon 嗎？
不行。依該試驗 protocol（EuroIntervention 2020;16:e329）：普通未塗藥氣球的「預擴張」是必須的，但 rotablation、雷射斑塊切除、cutting balloon、其他 DCB 等輔助工具在標的血管內「不被允許」。換句話說，這個乾淨的 RCT 條件刻意排除了切割氣球——所以它的好結果是在「相對單純、可只用普通氣球擴張」的 ISR 病灶取得的。真實世界 all-comers（如華人登錄）面對更複雜的 de novo 病灶，才更需要 cutting balloon 來控制剝離。這正是試驗 vs 臨床的張力點。
ISR 和 de novo 的病灶準備策略有何不同？
ISR 在既有支架金屬框內，剝離率極低（登錄 0.3%），準備相對單純、技術成功高（98.7%）；de novo 無支架支撐、易彈性回縮與剝離（7.3%），更需積極準備與謹慎判讀是否 bailout。
登錄的 MACE 13.9% 是不是比其他 DCB 試驗差？
不能直接比。本登錄含例行造影追蹤造成 detection bias，TVR 被高估（26.9% vs 4.9%）。改看「臨床驅動／未造影」族群，MACE 僅 4.9%（ISR 5.8%、de novo 3.2%），與其他臨床驅動試驗相當甚至更好。
AGENT 用更低藥量（2 µg vs 3 µg）會不會療效打折？
兩個 RCT（歐洲 ISR、日本 SV）主要終點皆達非劣性；新賦形劑 ATBC 提升藥物轉移效率，使較低藥量仍維持療效，並期望降低血管毒性。
為什麼 de novo 會出現「晚期管腔擴大」？
無永久金屬植入時，血管可發生正向重塑（positive remodeling）；登錄 de novo 有 37% 出現晚期管腔擴大，是 DCB「不留金屬」相較支架的獨特潛在好處。
