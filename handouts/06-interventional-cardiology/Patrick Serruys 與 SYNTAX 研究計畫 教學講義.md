## 3. SYNTAX 研究計畫總覽

**SYNTAX = SYNergy between percutaneous coronary intervention with TAXus and cardiac surgery**

### 研究計畫架構

```text
SYNTAX Score (2005) ─── 解剖複雜度評分工具
    │
SYNTAX I Trial (2005–2009) ─── PCI vs. CABG 隨機對照試驗 (n=1,800)
    │
    ├── 1-year results (NEJM, 2009)
    ├── 3-year results (EHJ, 2011)
    ├── 5-year results (Lancet, 2013)
    │       │
    │       └── SYNTAX Score II (Lancet, 2013) ─── 加入臨床變項的個人化評分
    │
    └── SYNTAXES: 10-year results (Lancet, 2019)
            │
            ├── Completeness of revascularization (Circulation, 2021)
            │
            └── SYNTAX Score II 2020 (Lancet, 2020) ─── 以 10 年數據重建
    
SYNTAX II Trial (2016–2022) ─── 新世代 PCI 策略 (n=454)
    │
    ├── 1-year results (EHJ, 2017)
    └── 5-year final results (EHJ, 2022)

SYNTAX III REVOLUTION (2017–2018) ─── CT-based Heart Team 決策 (n=223)
    │
    └── Main results (EHJ, 2018)
```

## 4. SYNTAX Score 的開發與演進

### SYNTAX Score (2005)

| 項目 | 內容 |
|------|------|
| 發表 | Sianos G, ..., Serruys PW. *EuroIntervention*. 2005;1(2):219-227 |
| 組成元素 | Leaman score + AHA classification + CTO score + Medina bifurcation classification + thrombus score + calcification |
| 功能 | 量化冠脈病變的解剖複雜度 |

**SYNTAX Score 分級**

| 分級 | 分數 | 臨床意義 |
|------|------|---------|
| Low | 0–22 | PCI 與 CABG 結果相當 |
| Intermediate | 23–32 | 需依個案評估 |
| High | ≥33 | CABG 優於 PCI |

### SYNTAX Score II (2013)

| 項目 | 內容 |
|------|------|
| 發表 | Farooq V, ..., Serruys PW. [*Lancet*. 2013;381:639-650](https://doi.org/10.1016/S0140-6736(13)60108-7) |
| 新增變項 | Age, creatinine clearance, LVEF, sex, COPD, peripheral vascular disease, unprotected left main |
| 驗證 | DELTA registry (n=2,891) + CREDO-Kyoto registry (n=3,896) |
| 優勢 | 針對個別病人分別預測 PCI 與 CABG 的 4 年死亡率 |

### SYNTAX Score II 2020

| 項目 | 內容 |
|------|------|
| 發表 | Takahashi K, ..., Serruys PW. [*Lancet*. 2020;396:1399-1412](https://doi.org/10.1016/S0140-6736(20)32114-0) |
| 改進 | 使用 SYNTAXES 10 年死亡率數據重新建模 |
| 變項 | Anatomical SYNTAX score, age, CrCl, LVEF, sex, COPD, PVD, diabetes |
| 外部驗證 | BEST trial (n=880) + PRECOMBAT trial (n=600) |
| 線上工具 | syntaxscore2020.com |

> **Pearl**: SYNTAX Score 的演進反映了「從群體到個人」的醫學趨勢——從純解剖評估 (2005) → 加入臨床變項 (2013) → 以長期數據優化 (2020)，逐步實現 **precision revascularization**。

## 5. SYNTAX Trial 系列結果

### SYNTAX I — 試驗設計

| 項目 | 內容 |
|------|------|
| 設計 | 多中心、隨機對照試驗 |
| 對象 | De novo 3-vessel disease 和/或 left main disease |
| 隨機分組 | PCI (TAXUS Express paclitaxel-eluting stent) vs. CABG |
| 隨機化人數 | **1,800 人** |
| 主要終點 | MACCE (death, MI, stroke, repeat revascularization) at 12 months |
| 亞群分析 | Left main disease (n=705), 3-vessel disease (n=1,095) |

### 結果演進

| 追蹤 | 發表 | MACCE: PCI vs. CABG | 關鍵發現 |
|------|------|---------------------|---------|
| **1 年** | [NEJM 2009](https://doi.org/10.1056/NEJMoa0804626) | 17.8% vs. 12.4% (P=0.002) | PCI 未達 noninferiority；repeat revascularization 驅動差異 |
| **3 年** | [EHJ 2011](https://doi.org/10.1093/eurheartj/ehr213) | 28.0% vs. 20.2% (P<0.001) | CABG 優勢持續；死亡率無顯著差異 |
| **5 年** | [Lancet 2013](https://doi.org/10.1016/S0140-6736(13)60141-5) | 37.3% vs. 26.9% (P<0.0001) | 3VD 高 SYNTAX score: 死亡率 CABG 顯著較低 |
| **10 年** | [Lancet 2019](https://doi.org/10.1016/S0140-6736(19)31997-X) | 死亡率: 24.2% vs. 24.0% (P=0.90) | 整體死亡率無差異；3VD: CABG 較優 (P=0.01) |

### Left Main Subgroup 結果

| 追蹤 | 發表 | 主要發現 |
|------|------|---------|
| 1 年 | [Circulation 2010](https://doi.org/10.1161/CIRCULATIONAHA.109.899211) | Low/intermediate SYNTAX score: PCI 為合理替代方案 |
| 5 年 | [Circulation 2014](https://doi.org/10.1161/CIRCULATIONAHA.113.006689) | 整體 MACCE 無顯著差異 (36.9% vs. 31.0%, P=0.12) |
| 10 年 | [Lancet 2019](https://doi.org/10.1016/S0140-6736(19)31997-X) | 死亡率無顯著差異 (26.0% vs. 28.2%, P=0.49) |

### SYNTAXES — Complete Revascularization 分析

| 項目 | 內容 |
|------|------|
| 發表 | Thuijs DJFM, ..., Serruys PW. [*Circulation*. 2021;144:96-109](https://doi.org/10.1161/CIRCULATIONAHA.120.046289) |
| Incomplete revascularization 比例 | PCI **43%** vs. CABG **27%** |
| PCI 組 | Residual SYNTAX score >8 與 10 年死亡率獨立相關 |
| CABG 組 | Incomplete revascularization 與死亡率 **無顯著關聯** |

> **Pearl**: 這項分析解釋了為何 PCI 在複雜病變中表現較差——因為 PCI 的 incomplete revascularization 比例更高，且對預後影響更大。CABG 的 collateral-based revascularization 可能提供額外保護。

## 6. SYNTAX II 與 SYNTAX III 新世代研究

### SYNTAX II Trial — 新世代 PCI 策略

**核心理念**: 如果以最先進的 PCI 技術 + 適當的病人選擇，能否達到與 CABG 相當的結果？

| 項目 | 內容 |
|------|------|
| 設計 | 前瞻性、多中心、單臂研究 (n=454) |
| 病人選擇 | **SYNTAX Score II** 引導（排除明確適合 CABG 的病人） |
| 生理學評估 | **iFR/FFR** 引導血運重建決策 |
| 支架 | Thin-strut bioresorbable polymer DES |
| 影像導引 | **IVUS** guidance |
| 藥物治療 | 新型 P2Y12 inhibitors |
| 對照 | 與 SYNTAX I 的 PCI 組和 CABG 組進行 propensity-matched 比較 |

**結果**

| 追蹤 | MACCE | 與 SYNTAX I PCI 比較 | 與 SYNTAX I CABG 比較 |
|------|-------|---------------------|---------------------|
| 1 年 | 10.6% | 17.4% (P=0.006) ✓ | 11.2% (P=0.74) ≈ |
| **5 年** | **21.5%** | **36.4% (P<0.001)** ✓✓ | **24.6% (P=0.35)** ≈ |

- All-cause death at 5 yr: SYNTAX II **8.1%** vs. SYNTAX I PCI 13.8% (P=0.013)
- Cardiac death at 5 yr: SYNTAX II **2.8%** vs. SYNTAX I PCI 8.4% (P<0.001)

> **Pearl**: SYNTAX II 證明了「**適當的病人選擇 + 現代 PCI 技術 = 結果可比 CABG**」。這五個要素缺一不可：SYNTAX Score II 選擇病人、iFR/FFR 引導、IVUS 影像導引、新型支架、最佳化藥物治療。

### SYNTAX III REVOLUTION — CT 取代侵入性血管攝影

| 項目 | 內容 |
|------|------|
| 發表 | Collet C, ..., Serruys PW. [*EHJ*. 2018;39:3689-3698](https://doi.org/10.1093/eurheartj/ehy581) |
| 設計 | 隨機試驗 (n=223)：Heart Team 使用 CCTA vs. invasive angiography 做決策 |
| CT 技術 | GE Revolution CT + CT-FFR |
| 主要發現 | 一致性 **93%** (Cohen's kappa = **0.82**, almost perfect agreement) |
| 額外發現 | CT-FFR 在約 **20%** 病人中改變了治療決策 |

> **Pearl**: SYNTAX III REVOLUTION 開啟了 **non-invasive Heart Team decision-making** 的時代——複雜冠脈疾病的血運重建策略可以在不做心導管的情況下，僅依據 CT 做出可靠決策。

## 7. SYNTAX 研究的臨床影響

### SYNTAX 研究改變了什麼？

| 影響領域 | 改變 |
|---------|------|
| **PCI vs. CABG 決策** | 從「一刀切」→ 基於 SYNTAX Score 的 **分層決策** |
| **Heart Team 概念** | 多學科團隊共同決策成為 guideline 標準 |
| **Left main PCI** | SYNTAX 為 left main PCI 提供了證據基礎 |
| **個人化醫療** | SYNTAX Score II 實現 individual-level 預測 |
| **PCI 技術演進** | SYNTAX II 推動了 physiology-guided + imaging-guided PCI |
| **非侵入性評估** | SYNTAX III 證明 CT 可取代 invasive angiography 做決策 |

### 現行 Guidelines 中的 SYNTAX Score

| Guideline | 建議 |
|-----------|------|
| ESC 2024 CCS Guidelines | SYNTAX Score 用於 3-vessel/left main disease 的 Heart Team 決策 |
| ACC/AHA Revascularization Guidelines | SYNTAX Score 作為解剖複雜度的參考 |
| ESC Myocardial Revascularization Guidelines | Low SYNTAX score (≤22) 的 left main disease → PCI 為 Class I 建議 |

### 10 Years of SYNTAX — 綜合回顧

| 項目 | 內容 |
|------|------|
| 發表 | Serruys PW, et al. [*JACC Asia*. 2023;3:409-430](https://doi.org/10.1016/j.jacasi.2023.03.014) |
| 內容 | 完整回顧 SYNTAX 計畫從 SYNTAX I 到 SYNTAXES、SYNTAX Score 到 SYNTAX Score II 2020 的演進 |
| 新發現 | 識別出新的 outcome determinants：完整血運重建度、手術技術、生理學評估的角色 |
