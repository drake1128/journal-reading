# Werner 的技術特點

> **「Respect the cap, read the collaterals, then touch the wire.」**

1. **Werner Collateral Connection (CC) Grade**（2003 *Circulation*）— 至今全球 retrograde 評估標準
   - **CC0** = 看不到
   - **CC1** = 連續細絲 (continuous, threadlike)
   - **CC2** = 連續 small side branch
2. **Antegrade purist**：細膩的 wire escalation + IVUS-guided proximal cap puncture
3. 對 dissection / re-entry 態度保守
4. **Physiology-driven**：先讀懂血管，再決定策略

# EUROCTO Trial 精華
## [Eur Heart J 2018 — PubMed 29722796](https://pubmed.ncbi.nlm.nih.gov/29722796/)

- **設計**：randomized multicenter, PCI vs Optimal Medical Therapy
- **技術成功率**：**86.3%**
- **主要結果**：PCI 組在
  - Angina frequency
  - Quality of life
  - Physical limitation
  顯著優於 OMT
- **3 年追蹤**：MACE 較低，無 hard endpoint 惡化
- **意義**：CTO PCI 從「臨床印象」進入 **evidence-based** 時代

# 給臨床的啟發 (1/2)

> **Pearl 1**：CTO PCI 的進步來自 **registry → algorithm → RCT** 的循環。Galassi 提供 epidemiology、Brilakis 提供 decision framework、Werner 提供 level-1 evidence。三者缺一不可。

> **Pearl 2**：學 CTO 不是學「絕招」，而是學**結構化決策**。Brilakis 的 *Manual* 與 [ctomanual.org](https://www.ctomanual.org/) 是台灣 fellow 最好的免費入門資源。

> **Pearl 3**：Werner 的 CC grade 是學 retrograde **第一個必須會的詞彙** — 沒有 CC1/CC2，retrograde 多半做不下去。

---

# 給臨床的啟發 (2/2)

> **Pearl 4**：Galassi 提醒我們「不是每條 CTO 都該打」。EUROCTO 的 inclusion criteria 明定 viable myocardium + symptomatic angina — **選對病人，比技術更重要**。

> **Pearl 5**：與其追隨單一大師，不如讀完三人的 review，建立**自己的 hybrid hybrid**。
