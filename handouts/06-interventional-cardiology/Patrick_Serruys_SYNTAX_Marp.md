# SYNTAX Score 的「拼圖」

## 冠脈病變複雜度評分系統 (2005)

```text
SYNTAX Score = Σ 每條病變的分數
每條病變分數 = 基礎分 (Leaman 權重 × 狹窄乘數) + 不良特徵加分
```

### 組成元素的來源

| 組成元素 | 原始出處 | 功能 |
|---------|---------|------|
| **Leaman Score** | Leaman et al., *Circulation* 1981 | 依血流比例賦予各血管節段權重 |
| **AHA 16-segment model** | AHA coronary segment classification | 定義冠脈解剖節段 |
| **Medina Classification** | Medina et al., *Rev Esp Cardiol* 2006 | 分叉病變分類 |
| CTO scoring | Expert consensus | 慢性完全阻塞特徵加分 |
| Calcification / thrombus | Expert consensus | 不良病變特徵加分 |

# Leaman Score (1981)

---

# Leaman Score — 起源

## [Leaman DM, Brower RW, Meester GT, **Serruys P**, van den Brand M](https://doi.org/10.1161/01.CIR.63.2.285)
## *Circulation*. 1981;63:285-299

- 過去的「1/2/3-vessel disease」分類 **將所有血管視為等值**
- 但 proximal LAD 狹窄 ≠ distal RCA 狹窄（供血範圍完全不同）

> 解決方案：依據每個冠脈節段 **對左心室血流供應的比例** 賦予不同權重

- 作者群來自 **Thoraxcenter, Erasmus University, Rotterdam**
- **Patrick Serruys 是共同作者** — 這項早期工作日後成為 SYNTAX Score 的基石

---

# Leaman Score — 血流分配原理

## Right-dominant circulation (~85% 病人)

```text
左心室血流供應比例：

    LCA 系統 84%                      RCA 系統 16%
    ┌────────┴────────┐                    │
  LAD 66%          LCx 33%            RCA = 1.0x (參考值)
   (of LCA)        (of LCA)
```

### 權重計算（以 RCA = 1.0 為基準）

| 血管 | 血流比例 | 計算方式 | 權重 |
|------|---------|---------|------|
| **Left Main** | 84% | 84/16 | **5.0** |
| **LAD system** | ~55% | 84/16 × 0.66 | **3.5** |
| **LCx system** | ~28% | 84/16 × 0.33 | **1.5** |
| **RCA system** | 16% | 參考基準 | **1.0** |

---

<!-- _class: small-text -->
# Leaman Score — 各節段權重 (Right-dominant)

| LCA 系統 | 權重 | RCA 系統 | 權重 |
|---------|------|---------|------|
| **Left main** | **5.0** | Proximal RCA | 1.0 |
| **Proximal LAD** | **3.5** | Mid RCA | 1.0 |
| Mid LAD | 2.5 | Distal RCA | 1.0 |
| Distal LAD | 1.0 | R-PDA | 1.0 |
| 1st Diagonal | 1.0 | R-PLB | 0.5 |
| 2nd Diagonal | 0.5 | | |
| **Proximal LCx** | **1.5** | | |
| Mid-Distal LCx | 0.5 | | |
| Obtuse Marginal | 1.0 | | |

> **Proximal LAD (3.5) 的權重是 RCA (1.0) 的 3.5 倍** — 反映其供血範圍差異

---

# Leaman Score — Left Dominance 的調整

## Left-dominant system (~8% 病人)

| 節段 | Right-dominant | **Left-dominant** | 原因 |
|------|---------------|-------------------|------|
| LM | 5.0 | **6.0** | LM 供應 100% LV 血流 |
| LCx | 1.5 | **2.5** | 接管 PDA/PLB 區域 |
| Mid-Distal LCx | 0.5 | **1.5** | 同上 |
| RCA | 1.0 | **0** | 不供血左心室 |

> **同一條 proximal LCx 狹窄**，在 left-dominant 病人的分數比 right-dominant **更高**

# Leaman Score — 狹窄嚴重度乘數與計算範例

| 狹窄嚴重度 | 乘數 | | 計算範例 (Right-dominant) | 權重 | 乘數 | 分數 |
|-----------|------|-|------------------------|------|------|------|
| Total occlusion (100%) | **× 5** | | 80% proximal LAD | 3.5 | × 1 | **3.5** |

# Medina Classification (2006)

---

# Medina Classification — 起源

## [Medina A, Suárez de Lezo J, Pan M. *Rev Esp Cardiol*. 2006;59(2):183](https://doi.org/10.1016/S1885-5857(06)60130-8)

- **Alfonso Medina** — Hospital Universitario de Gran Canaria, Las Palmas, Spain
- 僅是一封 **brief letter**，卻成為全球最廣泛使用的分叉病變分類

### 三位數二進位代碼 (a, b, c)
- **1** = 有顯著狹窄 (≥50%)；**0** = 無狹窄 (<50%)

```text
    Proximal MV (a)
         │
 ────────┼────────  Distal MV (b)
         │
    Side Branch (c)        Medina = (a, b, c)
```

---

# Medina Classification — 7 種類型

| Medina | MVp | MVd | SB | 圖示 | 類別 |
|--------|-----|-----|----|------|------|
| **(1,1,1)** | Yes | Yes | Yes | 全部受累 | **True bifurcation** |
| **(1,0,1)** | Yes | No | Yes | 近端MV + SB | **True bifurcation** |
| **(0,1,1)** | No | Yes | Yes | 遠端MV + SB | **True bifurcation** |
| (1,1,0) | Yes | Yes | No | MV 受累 | Non-true |
| (1,0,0) | Yes | No | No | 近端MV | Non-true |
| (0,1,0) | No | Yes | No | 遠端MV | Non-true |
| (0,0,1) | No | No | Yes | 僅 SB 開口 | Non-true |

> **True bifurcation** = Side branch 受累 (c = 1) → 手術策略更複雜

---

# Medina Classification — 為何成為標準？

| 優勢 | 說明 |
|------|------|
| **簡單** | 只需三個二進位數字，任何人都能記住 |
| **可重複性高** | Binary (有/無) 判斷，觀察者間一致性高 |
| **完整** | 7 種類型涵蓋所有可能組合 |
| **通用** | 純解剖描述，不預設治療策略 |
| **國際認可** | European Bifurcation Club (EBC) 官方採用 |

- **局限性**：未涵蓋分叉角度、血管大小、病變長度、鈣化程度

# SYNTAX Score 計算詳解

---

# SYNTAX Score — 計算步驟

```text
Step 1: 確定冠脈 dominance → 設定 Leaman 權重
Step 2: 辨識所有顯著病變 (≥50% stenosis, 血管 ≥1.5 mm)
Step 3: 基礎分 = 節段權重 × 狹窄乘數 (非阻塞性 ×2, 完全阻塞 ×5)
Step 4: 加上「不良特徵」加分
Step 5: 加總所有病變分數 = Total SYNTAX Score
```

> 注意：SYNTAX Score 的狹窄乘數與 Leaman 原始版不同 — 非阻塞性 **×2** (非 ×1)

---

<!-- _class: small-text -->
# SYNTAX Score — 不良特徵加分

| CTO 特徵 (每項 +1) | 加分 | | 分叉病變 (Medina) | 加分 |
|-------------------|------|-|------------------|------|
| CTO 年齡 > 3 個月 | **+1** | | SB 未受累 (c=0) | **+1** |
| Blunt stump | **+1** | | **SB 受累 (c=1)** | **+2** |
| Bridging collaterals | **+1** | | 分叉角度 < 70° | 額外 **+1** |
| 每個不可見的遠端節段 | **+1** | | | |
| CTO 處有 SB ≥1.5 mm | **+1** | | | |

---

<!-- _class: small-text -->
# SYNTAX Score — 其他不良特徵加分

| 特徵 | 定義 | 加分 |
|------|------|------|
| **Heavy calcification** | 多投影見環繞管腔不透光影 | **+2** |
| **Severe tortuosity** | ≥1 個 ≥90° 彎曲，或 ≥3 個 45-90° 彎曲 | **+2** |
| **Lesion length > 20 mm** | 病變長度超過 20 mm | **+1** |
| **Thrombus** | 多投影可見管腔內充盈缺損 | **+1** |
| **Diffuse / small vessel** | ≥75% 節段長度血管 < 2 mm | **+1/節段** |
| **Aorto-ostial** | 距主動脈開口 3 mm 以內 | **+1** |
| **Trifurcation** | 1 segment +3, 2 +4, 3 +5, 4 +6 | **+3~6** |

# SYNTAX Score — 計算範例

## 病人：Right-dominant，proximal LAD 70% 狹窄

| 項目 | 計算 | 分數 |
|------|------|------|
| 基礎分 | Proximal LAD (3.5) × 非阻塞性 (×2) | **7.0** |
| Heavy calcification | | **+2** |
| Length > 20 mm | | **+1** |
| Bifurcation (1,1,1) — SB 受累 | | **+2** |
| 分叉角度 < 70° | | **+1** |
| | **單一病變總分** | **13.0** |

> 這只是 **一條病變** 的分數！多條病變累加後，high SYNTAX score (≥33) 代表極為複雜的冠脈疾病

---

# SYNTAX Score — 已知局限性

| 局限性 | 說明 |
|--------|------|
| **不良特徵加分缺乏實證** | +1 / +2 的分配來自 **專家共識**，非 outcome-based |
| **觀察者間差異** | 分叉/三分叉判定的 inter-observer variability 最高 |
| **Leaman 權重不一致** | PDA 權重 (1.0) = proximal RCA (1.0)，違反血流守恆定律 |
| **純解剖評分** | 不含臨床變項 → 促使 SYNTAX Score II 的開發 |

> 這些局限性推動了 **SYNTAX Score II** (2013) 和 **SYNTAX Score II 2020** 的誕生

---

# SYNTAX I — 結果演進 (整體)

| 追蹤 | MACCE: PCI vs. CABG | P 值 | 死亡率: PCI vs. CABG |
|------|---------------------|------|---------------------|
| 1 年 | 17.8% vs. 12.4% | 0.002 | 3.5% vs. 3.5% |
| 3 年 | 28.0% vs. 20.2% | <0.001 | 6.7% vs. 5.3% |
| 5 年 | 37.3% vs. 26.9% | <0.0001 | 13.9% vs. 11.4% |
| **10 年** | — | — | **24.2% vs. 24.0% (P=0.90)** |

> **10 年整體死亡率：PCI = CABG**，但 MACCE 始終 CABG 較低（driven by repeat revascularization）

---

# SYNTAX I — 依疾病分層 (10 年死亡率)

| 亞群 | PCI | CABG | HR | P 值 |
|------|-----|------|-----|------|
| **整體** | 24.2% | 24.0% | — | 0.90 |
| **3-vessel disease** | **28.0%** | **21.1%** | 1.41 | **0.01** |
| **Left main** | 26.0% | 28.2% | — | 0.49 |

> **Key message**: 3-vessel disease → CABG 較優；Left main → PCI 與 CABG 相當

---

# SYNTAX I — 依 SYNTAX Score 分層

| SYNTAX Score | 3VD: PCI vs. CABG | Left Main: PCI vs. CABG |
|-------------|-------------------|------------------------|
| **Low (0–22)** | 結果相當 | 結果相當 |
| **Intermediate (23–32)** | CABG 漸優 | 結果相當 |
| **High (≥33)** | **CABG 顯著較優** | **CABG 較優** |

> SYNTAX Score 是決定血運重建策略的 **關鍵工具**

# Complete Revascularization 的重要性

## [Thuijs et al. *Circulation*. 2021;144:96-109](https://doi.org/10.1161/CIRCULATIONAHA.120.046289)

| 項目 | PCI | CABG |
|------|-----|------|
| Incomplete revascularization 比例 | **43%** | **27%** |
| Incomplete CR 與 10 年死亡率的關聯 | **獨立相關** (residual SS >8) | 無顯著關聯 |

> PCI 表現較差的部分原因：incomplete revascularization 比例高且影響大

| 個人化醫療 | SYNTAX Score II → **individual-level 預測** |
| PCI 技術 | SYNTAX II 推動 **physiology + imaging guided PCI** |
| 非侵入性評估 | SYNTAX III 證明 **CT 可取代 angiography** |

---

# Take Home Messages

> **1.** SYNTAX Score 是介入心臟學最重要的工具之一：將 PCI vs. CABG 決策從主觀判斷轉為 **客觀量化**

> **2.** 10 年追蹤顯示：Left main disease → PCI ≈ CABG；3-vessel disease → **CABG 較優**（尤其是 high SYNTAX score）

> **3.** SYNTAX II 證明了「**正確的病人 + 正確的技術 = PCI 可比 CABG**」

> **4.** SYNTAX III 開啟了 **non-invasive Heart Team decision-making** 的時代
