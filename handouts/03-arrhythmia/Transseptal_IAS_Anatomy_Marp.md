# 跨心房中膈穿刺與心房中膈解剖
## 以發育解剖為基礎的安全穿刺指引
### Transseptal Interventions and the Interatrial Septum
**讀書會共筆整理｜謝慕揚 MD, PhD, FESC** · 2026-06-04
[原文：Heart Rhythm 2026 (DOI 10.1016/j.hrthm.2026.04.029)](https://doi.org/10.1016/j.hrthm.2026.04.029)

---

# 一句話總結

- 安全 **transseptal 穿刺**建立在正確理解 **IAS 發育解剖**上
- 真「中膈」只有：**卵圓窩底 + 瓣膜 + 前下支柱**
- 常稱 *septum secundum* 的上緣 = 充脂肪的**心房壁深摺**，不是中膈
- **把摺疊當中膈穿 → 心包填塞**；正解：**對準卵圓窩底**

---

# 為什麼重要

- AF 電燒、左側旁路、LAAO、二尖瓣介入 → 都靠 **transseptal 進路**
- 傳統「primary + secondary septum 兩片肌肉重疊」的描述**不正確**
- 此迷思**直接導致穿刺併發症**；本文用發育學證據重新定義

---

# 什麼才是「真正的中膈」

> 定義：可移除而**不穿出心臟腔室**的部分。

| 構造 | 來源 |
|------|------|
| **卵圓窩底 (fossa ovalis)** | primary atrial septum |
| **瓣膜 (flap valve)** | 即 primary septum |
| **前下支柱 (anteroinferior buttress)** | vestibular spine 肌肉化 → 真正的「第二中膈」 |

> 真中膈 = 卵圓窩底 + 瓣膜 + 前下支柱。

---

# 迷思與致命後果

- **迷思**：上緣是可穿的 “septum secundum” 肌肉中膈
- **事實**：那是**心房壁深摺 (superior interatrial fold)**，內含**心外脂肪**
  - 解釋了所謂 “septum secundum **脂肪瘤/脂肪增生**”（脂肪堆在深摺內）
  - **把摺疊當中膈穿 → 針穿出心包 → tamponade**

> 「看似安全卻造成填塞」的根源。

---

# 安全穿刺：解剖標的

- 右股靜脈進路，**TEE / ICE 導引**（無超音波時用標誌 + biplane 透視）
- **最關鍵**：辨識並穿刺**源自 primary septum 的卵圓窩底**
  - 穿過**窩底**或**前下支柱** → **直接進入左房**
- 一般**寧低勿高**（偏低較安全，雖較費工）

> 口訣：**對準卵圓窩底、寧低勿高、避免過前**。

---

# 穿錯位置 → 後果

| 位置 | 後果 |
|------|------|
| **卵圓窩底 / 前下支柱** | ✅ 直接入左房（正確）|
| 上緣 / 後緣 | ❌ 心包腔 → **tamponade** |
| 後上緣 | ❌ 穿過心房間摺疊 → **填塞** |
| 過於偏前 | ❌ 主動脈**無冠竇** |

> 併發症幾乎都源於「把摺疊/邊緣當中膈」。

---

# Take-home

> **1.** 真中膈 = 卵圓窩底 + 瓣膜 + 前下支柱；其餘是心房壁摺疊。

> **2.** *septum secundum* 是充脂肪的上心房間摺疊 → 穿它會 **tamponade**。

> **3.** 安全穿刺**對準卵圓窩底**、**寧低勿高、避免過前**；**TEE/ICE 導引**。
