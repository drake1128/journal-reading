## 核心概念摘要

> **主旨**：許多遺傳性心臟病可以從外觀表型（phenotype）——包括骨骼肌肉異常、顏面特徵、神經學表現——早期辨識，進而啟動心臟篩檢。**看見外表，想到心臟。**
>
> **臨床意義**：心臟科醫師在診間遇到先天性心臟病患者時，應仔細檢查上肢、面容及神經肌肉系統；反之，骨科、復健科或神經科醫師發現特定外觀異常時，應轉介心臟科評估。

## 1. 核心概念

### 為什麼「看外表」能幫助診斷心臟病？

心臟與四肢、顏面結構在胚胎發育過程中，受到許多**共同的轉錄因子 (transcription factors)** 與**訊號傳遞路徑 (signaling pathways)** 的調控。當這些基因發生突變時，往往同時影響心臟和其他器官系統。

| 發育機制 | 共同受影響的系統 | 代表性症候群 |
|---------|-------------|-----------|
| T-box transcription factors | 心臟中隔 + 上肢橈側 | Holt-Oram (TBX5) |
| Neural crest cell migration | 大血管圓錐動脈幹 + 顏面 + 胸腺 | 22q11.2 deletion (TBX1) |
| RAS-MAPK pathway | 心臟瓣膜 + 生長 + 顏面 | Noonan (PTPN11) |
| Fibrillin / TGF-β pathway | 主動脈 + 骨骼結締組織 | Marfan (FBN1), Loeys-Dietz (TGFBR1/2) |
| Dystrophin complex | 心肌 + 骨骼肌 | Duchenne/Becker (DMD) |

### 心臟遺傳學的三大時代

| 時代 | 年代 | 技術 | 代表成就 |
|------|------|------|---------|
| **細胞遺傳學時代** | 1950s-1980s | Karyotyping, FISH | Down syndrome, Turner syndrome |
| **分子遺傳學時代** | 1990s-2010s | Sanger sequencing, linkage analysis | FBN1, TBX5, PTPN11 單基因定位 |

## 3. 病例回顧：Holt-Oram Syndrome

### 病例摘要（Hsieh CW et al., J Formosan Med Assoc, 1986）

此為**台灣首例報告**的 Holt-Oram syndrome，發表於長庚紀念醫院。

| 項目 | 內容 |
|------|------|
| **患者** | 19 歲女性 |
| **主訴** | 活動性呼吸困難 5 個月 |
| **上肢異常** | 雙側拇指發育不全（右側較嚴重）、右前臂旋後受限、右肘關節後方骨性突起、radial pulses 缺失 |
| **X 光發現** | 雙手第一掌骨及指骨發育不全、右手 trapezium 及 scaphoid 發育不全並半脫位、右橈骨頭向後脫位 |
| **心電圖** | Incomplete right bundle branch block |
| **胸部 X 光** | 肺血流增加、主肺動脈擴張 |
| **心臟超音波** | 右心室容積負荷增加、心室中隔異常運動、二尖瓣輕度脫垂 |
| **心導管** | Secundum type ASD，Qp/Qs = 1.5，左心室攝影示 posterior mitral leaflet 輕度脫垂 |
| **染色體檢查** | 正常（sporadic case） |
| **治療** | ASD patch closure 手術成功 |
| **特殊臨床意義** | 因上肢血管發育不良，右前臂橈動脈搏動缺失，心導管檢查改由**右股動脈及靜脈**執行 |

> **Pearl 1**：Holt-Oram syndrome 患者的上肢血管可能發育不良（hypoplastic radial arteries），**進行心導管檢查前務必評估上肢血管通路的可行性**。
>
> **Pearl 2**：此病例為 sporadic case（父母及手足無心臟或骨骼異常），提醒我們**約 60% 的 Holt-Oram syndrome 為 de novo 突變**，無家族史不能排除診斷。

## 4. Holt-Oram Syndrome 深入解析

### 4.1 定義與流行病學

| 項目 | 內容 |
|------|------|
| **別名** | Atrio-digital dysplasia, heart-hand syndrome type 1 |
| **基因** | *TBX5* (chromosome 12q24.21) |
| **遺傳模式** | Autosomal dominant |
| **發生率** | 約 1/100,000 活產 |
| **De novo 比例** | ~60% |
| **外顯率** | 上肢異常 100%；心臟缺損 ~75% |

### 4.2 心臟表現

| 心臟異常 | 頻率 | 說明 |
|---------|------|------|
| **ASD (secundum type)** | ~80% | 最常見的結構性心臟缺損 |
| **VSD** | 常見 | 特別是肌肉型心室中隔缺損 |
| **傳導異常** | ~30% | 從 1st degree AV block 到 complete heart block 進行性惡化 |
| **心房顫動 (AF)** | 變異 | Missense variants 風險較高 (48% vs 30%) |
| **Tetralogy of Fallot** | 罕見 | |
| **Ebstein anomaly** | 罕見 | |
| **擴張型心肌病 (DCM)** | 新發現 | 2020 年 Postma et al. 報告家族性 DCM 與 TBX5 突變相關 |

### 4.3 上肢骨骼表現（Radial Ray Defects）

上肢異常永遠涉及**橈側結構 (radial ray)**，**雙側但不對稱**，左側通常較嚴重。**下肢絕不受影響。**

| 嚴重度 | 表現 | 說明 |
|--------|------|------|
| **輕度** | Thenar hypoplasia | 可能僅靠 X 光才能發現 |
| **輕度** | Triphalangeal thumb | 最常見的拇指異常 |
| **中度** | Hypoplastic/absent thumb | 對掌功能受損 |
| **中度** | Carpal bone anomalies | Trapezium、scaphoid 發育不良或額外腕骨 |
| **重度** | Radial hypoplasia/aplasia | 橈骨短小或缺失 |
| **重度** | Radioulnar synostosis | 前臂旋轉受限 |
| **最重度** | Phocomelia | 肢體近端嚴重缺損 |

### 4.4 診斷標準（GeneReviews, 2025 更新）

**臨床診斷需同時具備：**

1. **Preaxial radial ray anomaly**（橈側上肢異常）
2. **本人或家族有心臟中隔缺損及/或傳導異常**
3. 符合 autosomal dominant 遺傳模式（但無家族史不能排除）

**分子確認**：*TBX5* 基因 heterozygous pathogenic variant

### 4.5 鑑別診斷

| 鑑別診斷 | 基因 | 與 Holt-Oram 的主要區別 |
|---------|------|----------------------|
| **Duane-radial ray syndrome** | *SALL4* | 合併 Duane anomaly（外展受限）、腎臟異常 |
| **Fanconi anemia** | *FANCA* 等 | 全血球減少、骨髓衰竭、DNA 斷裂試驗陽性 |
| **TAR syndrome** | *RBM8A* | 血小板低下、橈骨缺失但**拇指存在** |
| **Townes-Brocks syndrome** | *SALL1* | 肛門閉鎖、耳朵異常、腎臟異常 |
| **VACTERL association** | 多基因 | 脊椎、肛門、心臟、氣管食道瘻管、腎臟、肢體 |

### 4.6 追蹤與處置

| 項目 | 建議 |
|------|------|
| **心電圖** | 每年；有傳導異常者加做 Holter |
| **心臟超音波** | 依心臟科醫師建議；無結構性缺損者每 5 年 |
| **心臟手術** | ASD/VSD 標準修補 |
| **Pacemaker** | 進行性傳導異常至 complete heart block |
| **骨科/手外科** | 改善上肢功能 |
| **懷孕前評估** | 務必進行心臟功能評估 |
| **基因諮詢** | 50% 子代遺傳風險 |

## 5. TBX5 基因：從胚胎發育到精準醫學

### 5.1 TBX5 在胚胎發育的角色

TBX5 編碼一個 T-box transcription factor，在心臟與上肢的胚胎發育中扮演關鍵角色：

| 功能 | 說明 |
|------|------|
| **心臟中隔形成** | 調控心房及心室中隔的發育 |
| **傳導系統發育** | 建立特化的心臟傳導網絡 |
| **上肢模式形成** | 僅在前肢表現（不在後肢），解釋為何下肢不受影響 |
| **與其他轉錄因子協同** | 與 NKX2-5、GATA4 共同調控心臟基因表現 |
| **劑量敏感性** | 太少 → CHD/傳導異常；太多 → 心房顫動 |

### 5.2 基因型-表型相關性

| 突變類型 | 心臟表型 | 骨骼表型 |
|---------|---------|---------|
| **5' T-box missense** | 較嚴重心臟缺損 | 較輕 |
| **3' T-box missense** | 較輕 | 較嚴重骨骼缺損 |
| **Missense variants（整體）** | 心律不整風險較高 (48%) | 上肢異常較少 (64%) |
| **Protein-truncating variants** | 心律不整較少 (30%) | 上肢異常更頻繁 (85%) |
| **Gain-of-function** | 陣發性心房顫動 | 橈骨頭脫位、肩胛骨發育不良 |

### 5.3 TBX5 最新研究進展（2020-2026）

| 年份 | 研究 | 關鍵發現 |
|------|------|---------|
| **2020** | Postma et al., *Genet Med* | TBX5 致病變異與**家族性擴張型心肌病**相關，擴展心臟表型 |
| **2023** | Xiang et al., *npj Regen Med* | 發現 Tbx5 標記的心肌前驅細胞可去分化並啟動再生程序 |
| **2024** | Moller Nielsen et al., *Eur J Med Genet* | 系統性回顧 **108 個 TBX5 變異**，277 位患者的基因型-表型分析 |
| **2025** | Rivera-Madera et al., *G3* | 5 個 missense 突變的生物物理分析：影響蛋白穩定性與 DNA 結合親和力 |
| **2026** | Lazarevic et al., *Nat Cardiovasc Res* | TBX5 基因調控網絡的下調同時出現在 **AF 與 HF** 模型中 |
| **2026** | Kathiriya et al., *Development* | 完全缺失 TBX5 → 幾乎無心房心肌細胞生成；劑量不足 → 電生理異常 |
| **2026** | Kathiriya et al., *Nat Cardiovasc Res* | TBX5 建立心臟腔室邊界，邊界破壞導致先天性心臟缺損 |
| **2026** | Leonard et al., *bioRxiv* | 以 microRNA 抑制技術活化 Tbx5 等心臟轉錄因子，小鼠心肌梗塞後 EF 從 22% 恢復至 56% |

> **Pearl**：TBX5 的研究正從「先天性心臟病基因」進化為「心臟再生與精準醫學」的關鍵靶點。AF 與 HF 可能共享 TBX5 調控網絡的失調，這為未來治療提供了新方向。

## 6. 從外觀辨識心臟病：骨骼肌肉系統相關症候群

### 6.1 綜覽：骨骼異常合併心臟病的症候群

| 症候群 | 基因/染色體 | 遺傳 | 骨骼/外觀線索 | 心臟表現 |
|--------|-----------|------|------------|---------|
| **Holt-Oram** | *TBX5* | AD | 拇指三指節/缺失、橈骨發育不全、左右不對稱 | ASD, VSD, conduction disease |
| **Marfan** | *FBN1* | AD | 身材高瘦、蜘蛛指（arachnodactyly）、漏斗胸/雞胸、水晶體脫位 | 主動脈根部擴張/剝離、MVP |
| **Loeys-Dietz** | *TGFBR1/2* | AD | 眼距過寬、雙叉懸雍垂、動脈蜿蜒、翻譯皮膚、杵狀足 | 主動脈瘤/剝離（更年輕、更小徑即發生） |
| **Ehlers-Danlos (vascular)** | *COL3A1* | AD | 皮膚薄透明（可見靜脈）、容易瘀青、小關節過動 | 動脈自發性破裂/剝離 |
| **Turner** | 45,X | 散發 | 矮小、蹼頸、盾狀胸、肘外翻、出生時手腳水腫 | Bicuspid aortic valve, coarctation |
| **Ellis-van Creveld** | *EVC/EVC2* | AR | 短肢型侏儒、軸後多指、指甲發育不良 | Common atrium, ASD (primum) |
| **Cornelia de Lange** | *NIPBL* | AD | 眉毛相連、長睫毛、短鼻上翻、薄唇、上肢缺指/短肢 | ASD, VSD, PS |
| **Rubinstein-Taybi** | *CREBBP* | AD | **寬拇指及大腳趾**（角度彎曲）、鷹勾鼻、身材矮小 | ASD, VSD, PDA |

### 6.2 重點比較：拇指異常的鑑別

| 特徵 | Holt-Oram | Rubinstein-Taybi | Cornelia de Lange | TAR |
|------|-----------|-----------------|------------------|-----|
| **拇指形態** | 三指節/缺失/發育不全 | 寬大、角度彎曲 | 近端置位的小拇指 | **拇指存在**但橈骨缺失 |
| **大腳趾** | 正常 | 寬大 | 正常 | 正常 |
| **其他骨骼** | 橈骨、腕骨異常 | 脊椎異常 | 上肢缺指/短肢 | 橈骨缺失 |
| **心臟** | ASD, VSD | ASD, VSD, PDA | ASD, VSD, PS | 罕見（但有 ASD/TOF 報告） |
| **智力** | 正常 | 智能障礙 | 智能障礙 | 正常 |

> **Pearl**：看到拇指異常，務必檢查心臟。但不同的拇指異常型態指向不同的基因症候群——**三指節/缺失 → Holt-Oram；寬大彎曲 → Rubinstein-Taybi；橈骨缺失但拇指存在 → TAR。**

### 6.3 結締組織疾病的主動脈病變比較

| 特徵 | Marfan | Loeys-Dietz | Vascular EDS |
|------|--------|-------------|-------------|
| **基因** | *FBN1* | *TGFBR1/2/SMAD3/TGFB2/3* | *COL3A1* |
| **主動脈病變特徵** | 主動脈根部擴張為主 | 全動脈系統瘤/剝離，更年輕發病 | 中型動脈自發性破裂 |
| **手術閾值** | 主動脈根部 ≥50 mm | **更低閾值**（可在 <40 mm 即剝離） | 手術風險極高，組織脆弱 |
| **骨骼外觀線索** | 蜘蛛指、臂展 > 身高、漏斗胸 | 杵狀足、頸椎不穩 | 小關節過動、皮膚薄 |
| **獨特線索** | **水晶體脫位** | **雙叉懸雍垂** + **眼距過寬** | **皮膚薄透明可見靜脈** |

## 7. 從外觀辨識心臟病：顏面特徵相關症候群

### 7.1 綜覽：顏面特徵合併心臟病的症候群

| 症候群 | 基因/染色體 | 遺傳 | 顏面/外觀線索 | 最典型心臟表現 |
|--------|-----------|------|------------|-------------|
| **Down** | Trisomy 21 | 散發 | 平臉、上斜眼裂、內眥贅皮、Brushfield 斑點、單一掌紋、肌張力低下 | **AVSD** (~40%) |
| **Noonan** | *PTPN11* 等 | AD | 矮小、寬頸/蹼頸、眼距過寬、下斜眼裂、低位耳、漏斗胸 | **PS** (~70%), HCM |
| **Williams** | 7q11.23 del | AD (de novo) | **精靈面容**：寬額、眶周飽滿、星狀虹膜、扁鼻樑、長人中、寬嘴厚唇 | **SVAS**, peripheral PS |
| **22q11.2 deletion** | 22q11.2 del (*TBX1*) | AD (de novo) | 長臉、眼皮下垂、球鼻、小耳、顎裂/鼻音、低血鈣、免疫缺損 | **Conotruncal defects**: TOF, interrupted aortic arch type B |
| **Alagille** | *JAG1* | AD | **三角臉**：寬額、尖下巴、深凹眼、直鼻、蝴蝶椎、膽汁鬱積 | **Peripheral PS** (~97%) |
| **CHARGE** | *CHD7* | AD (de novo) | Coloboma、後鼻孔閉鎖、杯狀耳、顱神經功能障礙 | Conotruncal defects, AVSD |
| **Kabuki** | *KMT2D* | AD | 長眼裂、下眼瞼外翻、弓形眉（外側稀疏）、杯狀耳、胎兒指墊 | ASD, VSD, CoA |
| **LEOPARD** | *PTPN11* | AD | **多發性雀斑（lentigines）**、咖啡斑 | **HCM** (>90%) |

### 7.2 重點比較：矮小合併心臟病

| 特徵 | Noonan | Turner | Down | Williams |
|------|--------|--------|------|---------|
| **性別** | 男女均可 | **僅女性** | 男女均可 | 男女均可 |
| **核型** | 正常 (46,XX/XY) | **45,X** | **47,XX/XY,+21** | 正常（微缺失） |
| **頸部** | 蹼頸 | 蹼頸 | 短頸 | 正常 |
| **最典型心臟** | PS, HCM | BAV, CoA | AVSD | SVAS |
| **智力** | 輕度受影響 | 正常 | 智能障礙 | 輕-中度障礙 |
| **個性特徵** | — | — | — | **過度友善**（cocktail party personality） |

> **Pearl**：Noonan syndrome 過去被稱為「男性 Turner」，但 Noonan 可發生於兩性、核型正常、心臟以 PS/HCM 為主；Turner 僅限女性、45,X、心臟以 BAV/CoA 為主。

## 8. 從外觀辨識心臟病：神經肌肉疾病相關心臟病變

### 8.1 綜覽：神經肌肉疾病合併心臟病

| 疾病 | 基因 | 遺傳 | 神經肌肉表現 | 心臟表現 |
|------|------|------|-----------|---------|
| **Duchenne MD** | *DMD* (dystrophin) | XR | 近端肌無力、小腿假性肥大、Gowers' sign、~12 歲失去行走能力 | **DCM**（幾乎所有 DMD 患者 18 歲前出現）、心肌纖維化 |
| **Becker MD** | *DMD* (dystrophin) | XR | 較晚發病、較輕的肌無力 | DCM 可能**先於**骨骼肌無力出現 |
| **Myotonic dystrophy (DM1)** | *DMPK* (CTG repeat) | AD | 肌強直、遠端肌無力、前額禿、眼瞼下垂、「斧頭臉」、白內障 | **傳導異常**（1-3 度 AV block、BBB）、AF/AFL、VT、猝死 |
| **Emery-Dreifuss MD** | *EMD* / *LMNA* | XR / AD | **早期攣縮**（跟腱、肘、後頸）、肱骨-腓骨型肌無力 | **心房停頓/靜止**、AV block（需 pacemaker）、DCM（LMNA 型猝死風險高） |
| **Friedreich ataxia** | *FXN* (GAA repeat) | AR | 進行性步態及肢體共濟失調、構音障礙、深腱反射消失、本體感覺喪失、弓形足、脊椎側彎 | **HCM**（同心型，~65-75%）、可進展至 DCM、AF |
| **Limb-girdle MD (LGMD)** | 多基因 | AR/AD | 肢帶型肌無力 | DCM（特定亞型如 LGMD2I/*FKRP*） |
| **Kearns-Sayre syndrome** | mtDNA deletion | 母系遺傳 | 進行性外眼肌麻痺 (PEO)、視網膜色素病變 | **傳導異常**（complete heart block）、DCM |

### 8.2 神經肌肉疾病心臟篩檢建議

| 疾病 | ECG | Echocardiography | Holter | 心臟 MRI | 特殊注意 |
|------|-----|------------------|--------|---------|---------|
| **Duchenne/Becker** | 每年 | 每年（≥10 歲） | 有症狀時 | 建議 | 心肌纖維化以**下外側壁**為主（late gadolinium enhancement） |
| **Myotonic dystrophy** | 每年 | 每 2-3 年 | **每年** | 有症狀時 | PR interval ≥240 ms 或 QRS ≥120 ms → 考慮 EPS/pacemaker |
| **Emery-Dreifuss** | 每年 | 每 1-2 年 | **每年** | 有症狀時 | LMNA 型：即使有 pacemaker 仍有猝死風險 → 考慮 ICD |
| **Friedreich ataxia** | 每年 | 每 1-2 年 | 有症狀時 | 建議 | HCM 可能被 scoliosis/chest deformity 影響超音波窗 |

> **Pearl**：**Myotonic dystrophy 和 Emery-Dreifuss MD 的心臟致死風險最高**——前者可在肌肉症狀輕微時即發生猝死（VT），後者的 LMNA 型即使裝了 pacemaker 仍有 VT 猝死風險，需考慮 ICD。

### 8.3 2022 HRS Expert Consensus：神經肌肉疾病心律不整風險管理

2022 年 Heart Rhythm Society 發表的專家共識聲明（Towbin et al.）提供了系統性的心臟評估與治療建議：

| 建議 | 適用疾病 | 內容 |
|------|---------|------|
| **年度 ECG + Holter** | DM1, Emery-Dreifuss, LMNA-related | 即使無症狀也需定期監測傳導系統 |
| **EPS（電生理檢查）** | DM1 | PR ≥240 ms, QRS ≥120 ms, 或 2nd/3rd degree AV block |
| **Pacemaker** | DM1, Emery-Dreifuss | 進行性 AV block |
| **ICD** | LMNA-related, DM1（高風險） | LMNA + ≥2 risk factors (NSVT, LVEF <45%, male, non-missense variant) |
| **ACEi/ARB** | Duchenne/Becker | 即使 LVEF 正常也考慮早期使用（延緩 DCM 發展） |

## 9. 臨床診斷流程：表型導向的心臟篩檢

### 9.1 系統化方法：看到什麼 → 想到什麼 → 做什麼

| 臨床觀察 | 懷疑診斷 | 建議檢查 |
|---------|---------|---------|
| 拇指三指節/缺失 + 前臂異常 | **Holt-Oram** | ECG + Echo + *TBX5* 基因檢測 |
| 身材高瘦 + 蜘蛛指 + 水晶體脫位 | **Marfan** | 主動脈根部 CT/MRI + *FBN1* |
| 矮小 + 蹼頸 + 下斜眼裂 | **Noonan** | Echo (PS/HCM) + *PTPN11* panel |
| 矮小 + 蹼頸 + 盾狀胸（女性） | **Turner** | Karyotype + Echo (BAV/CoA) |
| 平臉 + 單一掌紋 + 肌張力低下 | **Down** | Karyotype + Echo (AVSD) |
| 精靈面容 + 過度友善 | **Williams** | Echo (SVAS) + FISH/MLPA 7q11.23 |
| 長臉 + 鼻音 + 低血鈣 | **22q11.2 deletion** | Echo + FISH/MLPA 22q11.2 |
| 三角臉 + 膽汁鬱積 + 蝴蝶椎 | **Alagille** | Echo (peripheral PS) + *JAG1* |
| 眼距過寬 + 雙叉懸雍垂 | **Loeys-Dietz** | CTA 全動脈系統 + *TGFBR1/2* |
| 多發性雀斑（lentigines） | **LEOPARD** | Echo (HCM) + *PTPN11* |
| 寬拇指/大腳趾 + 鷹勾鼻 | **Rubinstein-Taybi** | Echo + *CREBBP* |
| 小腿假性肥大 + Gowers' sign | **Duchenne** | ECG + Echo + CK + *DMD* |
| 肌強直 + 前額禿 + 白內障 | **Myotonic dystrophy** | ECG + Holter + *DMPK* |
| 早期肘/跟腱攣縮 + 肌無力 | **Emery-Dreifuss** | ECG + Holter + *EMD/LMNA* |
| 進行性共濟失調 + 弓形足 | **Friedreich ataxia** | Echo (HCM) + *FXN* |

### 9.2 速記口訣

```text
Phenotype-to-Heart 速記：

骨骼看心臟：
  拇指異常 → ASD (Holt-Oram)
  蜘蛛指   → 主動脈 (Marfan)
  寬拇指   → 中隔缺損 (Rubinstein-Taybi)
  多指     → 單心房 (Ellis-van Creveld)

面容看心臟：
  精靈臉   → SVAS (Williams)
  長臉鼻音 → TOF (22q11.2)
  三角臉   → peripheral PS (Alagille)
  雀斑     → HCM (LEOPARD)

肌肉看心臟：
  小腿肥大 → DCM (Duchenne)
  前額禿   → 傳導異常 (DM1)
  早期攣縮 → AV block (Emery-Dreifuss)
  共濟失調 → HCM (Friedreich)
```

## 10. 結論與臨床要點

### 十大 Take-Home Messages

| # | 要點 |
|---|------|
| 1 | 心臟與四肢、面容在胚胎發育中共享基因調控路徑——**外觀異常是心臟病的窗口** |
| 2 | Holt-Oram syndrome 是心臟-肢體症候群的典範：ASD + 橈側上肢缺損，由 **TBX5** 基因突變所致 |
| 3 | ~60% Holt-Oram 為 de novo 突變——**無家族史不能排除診斷** |
| 4 | Holt-Oram 患者上肢血管可能發育不良——**心導管前務必評估血管通路** |
| 5 | TBX5 具有劑量敏感性：不足 → CHD；過多 → AF——**未來精準醫學的重要靶點** |
| 6 | 結締組織疾病（Marfan、Loeys-Dietz、vascular EDS）各有獨特外觀線索——**水晶體脫位、雙叉懸雍垂、透明皮膚** |
| 7 | RASopathy（Noonan 家族）以**矮小 + 顏面特徵 + PS/HCM** 為特色 |
| 8 | 神經肌肉疾病的心臟併發症是主要致死原因——**DM1 和 LMNA-Emery-Dreifuss 猝死風險最高** |
| 9 | 2022 HRS 共識聲明提供了神經肌肉疾病心律不整管理的系統性建議 |
| 10 | 在遺傳性心臟病時代，**多專科團隊合作**（心臟科 + 遺傳科 + 骨科/神經科）是最佳照護模式 |
