# 第一部分：核心概念

---

# 為什麼「看外表」能診斷心臟病？

## 心臟與四肢/面容共享胚胎發育基因路徑

| 發育機制 | 影響系統 | 代表症候群 |
|---------|---------|---------|
| T-box transcription factors | 心臟中隔 + 上肢橈側 | **Holt-Oram** (TBX5) |
| Neural crest cell migration | 大血管 + 顏面 + 胸腺 | **22q11.2 deletion** (TBX1) |
| RAS-MAPK pathway | 心臟瓣膜 + 生長 + 顏面 | **Noonan** (PTPN11) |
| Fibrillin / TGF-β pathway | 主動脈 + 骨骼結締組織 | **Marfan** (FBN1) |
| Dystrophin complex | 心肌 + 骨骼肌 | **Duchenne** (DMD) |

> **核心原則**：一個基因突變 → 同時影響多個器官系統 → **看見外表，想到心臟**

# 第二部分：基因醫學在心臟病學的歷史

---

# 心臟遺傳學的三大時代

| 時代 | 年代 | 技術 | 代表成就 |
|------|------|------|---------|
| **細胞遺傳學** | 1950s-1980s | Karyotyping, FISH | Down syndrome (trisomy 21), Turner (45,X) |
| **分子遺傳學** | 1990s-2010s | Sanger sequencing | FBN1, TBX5, PTPN11 單基因定位 |
| **基因體醫學** | 2010s-present | NGS, WES, WGS, CRISPR | 多基因風險分數、基因治療、iPSC |

---

# 關鍵里程碑

| 年代 | 事件 | 意義 |
|------|------|------|
| **1959** | Lejeune 發現 trisomy 21 | 首個染色體 → CHD 的連結 |
| **1960** | **Holt & Oram** 描述心臟-肢體症候群 | 心臟-肢體典範 |
| **1991** | Dietz 發現 *FBN1* → Marfan | 結締組織病進入分子時代 |
| **1997** | **Basson 發現 *TBX5* → Holt-Oram** | 心臟發育轉錄因子里程碑 |
| **2001** | *PTPN11* → Noonan | RAS-MAPK pathway 心臟病 |
| **2005** | Loeys 描述 Loeys-Dietz (*TGFBR1/2*) | TGF-β 主動脈病變新實體 |
| **2018** | AHA: Genetic Basis for CHD | 系統性回顧 CHD 遺傳基礎 |
| **2026** | TBX5 調控網絡連結 AF 與 HF | 精準醫學最前沿 |

# 第三部分：病例回顧
# Holt-Oram Syndrome — 台灣首例

---

# 病例摘要

## Hsieh CW et al., J Formosan Med Assoc, 1986 — 長庚紀念醫院

| 項目 | 內容 |
|------|------|
| **患者** | 19 歲女性，裁縫工 |
| **主訴** | 活動性呼吸困難 5 個月 |
| **上肢異常** | 雙側拇指發育不全（右 > 左）、右前臂旋後受限、radial pulses **缺失** |
| **X 光** | 雙手第一掌骨/指骨發育不全、右手腕骨半脫位、右橈骨頭後方脫位 |
| **ECG** | Incomplete RBBB |
| **Echo** | RV volume overload、MVP |
| **心導管** | **Secundum ASD**, Qp/Qs = 1.5 |
| **治療** | ASD patch closure — 成功 |

---

# 病例的臨床啟示

> **Pearl 1**：上肢血管可能發育不良 → **心導管前務必評估血管通路**
> 本案 radial pulses 缺失 → 改由**右股動脈及靜脈**執行

> **Pearl 2**：約 **60%** Holt-Oram 為 de novo 突變
> 本案父母及手足均正常（sporadic case） → **無家族史不能排除診斷**

> **Pearl 3**：上肢異常可能很微妙
> 有時僅靠 **X 光** 才能發現骨骼變化

# 第四部分：Holt-Oram Syndrome 深入解析

---

# Holt-Oram Syndrome 概要

| 項目 | 內容 |
|------|------|
| **基因** | *TBX5* (12q24.21) |
| **遺傳** | Autosomal dominant |
| **發生率** | ~1/100,000 活產 |
| **De novo** | ~60% |
| **上肢外顯率** | **100%** |
| **心臟外顯率** | ~75% |

### 診斷標準（GeneReviews 2025）
1. Preaxial **radial ray** anomaly
2. 本人或家族有心臟**中隔缺損**或**傳導異常**
3. Autosomal dominant 遺傳模式

---

# 心臟表現

| 心臟異常 | 頻率 | 說明 |
|---------|------|------|
| **ASD (secundum)** | ~80% | 最常見 |
| **VSD** | 常見 | 肌肉型中隔缺損 |
| **傳導異常** | ~30% | 1st degree AV block → complete heart block（進行性） |
| **AF** | 變異 | Missense variants 風險較高 |
| **DCM** | 新發現 | 2020 年新增的心臟表型 |

> **Note**：TBX5 具有**劑量敏感性** — 不足 → CHD；過多 → AF

---

# 上肢骨骼表現：Radial Ray Defects

## 永遠是**橈側** (radial side)、**雙側不對稱**、**左側較嚴重**、**下肢絕不受影響**

| 嚴重度 | 表現 |
|--------|------|
| 輕度 | Thenar hypoplasia（可能僅 X 光才能發現） |
| 輕度 | **Triphalangeal thumb**（最常見） |
| 中度 | Hypoplastic/absent thumb |
| 中度 | Carpal bone anomalies（trapezium、scaphoid） |
| 重度 | Radial hypoplasia/aplasia |
| 重度 | Radioulnar synostosis（前臂旋轉受限） |
| 最重度 | Phocomelia |

---

# 鑑別診斷：拇指異常的比較

| 特徵 | Holt-Oram | Rubinstein-Taybi | TAR | Fanconi Anemia |
|------|-----------|-----------------|-----|----------------|
| **拇指** | 三指節/缺失 | **寬大**彎曲 | **存在**（橈骨缺失） | 缺失/發育不全 |
| **大腳趾** | 正常 | **寬大** | 正常 | 正常 |
| **心臟** | ASD, VSD | ASD, VSD, PDA | 罕見 | 罕見 |
| **血液** | 正常 | 正常 | **血小板低下** | **全血球減少** |
| **智力** | 正常 | 障礙 | 正常 | 正常 |
| **基因** | *TBX5* | *CREBBP* | *RBM8A* | *FANCA* 等 |

---

# TBX5 最新研究進展 (2020-2026)

| 年份 | 研究 | 關鍵發現 |
|------|------|---------|
| 2020 | Postma, *Genet Med* | TBX5 → **familial DCM** |
| 2024 | Moller Nielsen, *Eur J Med Genet* | **108 variants** 系統性回顧 |
| 2025 | Rivera-Madera, *G3* | Missense mutations 影響蛋白穩定性/DNA結合 |
| 2026 | Lazarevic, *Nat Cardiovasc Res* | TBX5 網絡失調同時出現在 **AF 與 HF** |
| 2026 | Kathiriya, *Development* | TBX5 為**心房心肌細胞命運**的主調控因子 |
| 2026 | Leonard, *bioRxiv* | microRNA 活化 Tbx5 → MI 後 EF 22%→56% |

> **Pearl**：TBX5 正從「先天性心臟病基因」進化為「**心臟再生與精準醫學**」的關鍵靶點

# 第五部分：骨骼肌肉異常 → 心臟病

---

# 骨骼異常合併心臟病

| 症候群 | 基因 | 遺傳 | 骨骼線索 | 心臟 |
|--------|------|------|---------|------|
| **Holt-Oram** | *TBX5* | AD | 拇指三指節/缺失、橈骨異常 | ASD, VSD |
| **Marfan** | *FBN1* | AD | 蜘蛛指、漏斗胸、水晶體脫位 | 主動脈根部擴張、MVP |
| **Loeys-Dietz** | *TGFBR1/2* | AD | 杵狀足、頸椎不穩、雙叉懸雍垂 | 主動脈瘤（更年輕更小徑） |
| **Ehlers-Danlos IV** | *COL3A1* | AD | 皮膚薄透明、容易瘀青 | 動脈自發性破裂 |
| **Turner** | 45,X | 散發 | 矮小、蹼頸、盾狀胸、肘外翻 | BAV, CoA |
| **Ellis-van Creveld** | *EVC* | AR | 短肢侏儒、多指、指甲異常 | Common atrium |
| **Rubinstein-Taybi** | *CREBBP* | AD | **寬拇指/大腳趾**、鷹勾鼻 | ASD, VSD, PDA |
| **Cornelia de Lange** | *NIPBL* | AD | 眉毛相連、上肢缺指 | ASD, VSD, PS |

---

# 結締組織疾病：主動脈病變比較

| 特徵 | Marfan | Loeys-Dietz | Vascular EDS |
|------|--------|-------------|-------------|
| **基因** | *FBN1* | *TGFBR1/2* | *COL3A1* |
| **主動脈** | 根部擴張 | **全動脈**瘤/剝離 | 中型動脈**破裂** |
| **手術閾值** | ≥50 mm | **更低**（<40 mm 可剝離） | **極高風險**組織脆弱 |
| **獨特線索** | **水晶體脫位** | **雙叉懸雍垂 + 眼距過寬** | **透明皮膚可見靜脈** |

> **Pearl**：遇到年輕主動脈剝離 → 仔細看眼睛（Marfan）、張嘴看懸雍垂（Loeys-Dietz）、看皮膚（vascular EDS）

# 第六部分：顏面特徵 → 心臟病

---

# 顏面特徵合併心臟病

| 症候群 | 顏面線索 | 最典型心臟 |
|--------|---------|---------|
| **Down** | 平臉、上斜眼裂、單一掌紋 | **AVSD** (~40%) |
| **Noonan** | 矮小、蹼頸、下斜眼裂 | **PS**, HCM |
| **Williams** | **精靈面容**、星狀虹膜、寬嘴厚唇 | **SVAS** |
| **22q11.2 del** | 長臉、球鼻、顎裂/鼻音、低血鈣 | **TOF**, IAA type B |
| **Alagille** | **三角臉**、膽汁鬱積、蝴蝶椎 | **Peripheral PS** |
| **CHARGE** | Coloboma、後鼻孔閉鎖、杯狀耳 | TOF, AVSD |
| **Kabuki** | 長眼裂、弓形眉、胎兒指墊 | ASD, VSD, CoA |
| **LEOPARD** | **多發性雀斑** | **HCM** (>90%) |

---

# 矮小合併心臟病：鑑別比較

| 特徵 | Noonan | Turner | Down | Williams |
|------|--------|--------|------|---------|
| **性別** | 男女 | **僅女性** | 男女 | 男女 |
| **核型** | 正常 | **45,X** | **47,+21** | 正常（微缺失） |
| **頸部** | 蹼頸 | 蹼頸 | 短頸 | 正常 |
| **心臟** | PS, HCM | BAV, CoA | **AVSD** | **SVAS** |
| **智力** | 輕度↓ | 正常 | 障礙 | 輕-中度↓ |
| **個性** | — | — | — | **過度友善** |

> **Pearl**：Noonan ≠ 「男性 Turner」— Noonan 兩性可發、核型正常、PS/HCM；Turner 僅女性、45,X、BAV/CoA

# 第七部分：神經肌肉疾病 → 心臟病

---

# 神經肌肉疾病合併心臟病

| 疾病 | 基因 | 遺傳 | 神經肌肉線索 | 心臟 |
|------|------|------|-----------|------|
| **Duchenne** | *DMD* | XR | 小腿假性肥大、Gowers' sign | **DCM** |
| **Becker** | *DMD* | XR | 較晚較輕肌無力 | DCM（可先於肌無力） |
| **DM1** | *DMPK* | AD | 肌強直、前額禿、斧頭臉、白內障 | **傳導異常、VT、猝死** |
| **Emery-Dreifuss** | *EMD/LMNA* | XR/AD | **早期攣縮**（肘、跟腱、後頸） | AV block、**心房停頓**、DCM |
| **Friedreich** | *FXN* | AR | 共濟失調、弓形足、脊椎側彎 | **HCM** (~65-75%) |
| **Kearns-Sayre** | mtDNA | 母系 | 外眼肌麻痺、視網膜色素病變 | Complete heart block |

---

# 心臟篩檢建議

| 疾病 | ECG | Echo | Holter | 特殊注意 |
|------|-----|------|--------|---------|
| **Duchenne/Becker** | 每年 | 每年（≥10 歲） | 有症狀時 | 心肌纖維化以**下外側壁**為主 |
| **DM1** | 每年 | 每 2-3 年 | **每年** | PR ≥240 ms / QRS ≥120 ms → EPS |
| **Emery-Dreifuss** | 每年 | 每 1-2 年 | **每年** | LMNA 型：pacemaker 不夠 → 考慮 **ICD** |
| **Friedreich** | 每年 | 每 1-2 年 | 有症狀時 | Scoliosis 影響超音波窗 |

> **Pearl**：**DM1 和 LMNA-Emery-Dreifuss 的猝死風險最高** — DM1 可在肌肉症狀輕微時猝死；LMNA 型即使有 pacemaker 仍需考慮 ICD

---

# 2022 HRS Consensus：神經肌肉疾病心律管理

| 建議 | 適用 | 內容 |
|------|------|------|
| 年度 ECG + Holter | DM1, Emery-Dreifuss, LMNA | 即使無症狀也需監測 |
| EPS | DM1 | PR ≥240 ms, QRS ≥120 ms |
| Pacemaker | DM1, Emery-Dreifuss | 進行性 AV block |
| **ICD** | **LMNA** | ≥2 risk factors (NSVT, LVEF <45%, male, non-missense) |
| ACEi/ARB | Duchenne/Becker | **即使 LVEF 正常**也考慮早期使用 |

# 第八部分：臨床診斷流程

---

# 表型導向的心臟篩檢

| 看到什麼 | 想到什麼 | 做什麼 |
|---------|---------|---------|
| 拇指三指節/缺失 + 前臂異常 | **Holt-Oram** | ECG + Echo + *TBX5* |
| 蜘蛛指 + 水晶體脫位 | **Marfan** | 主動脈 CT/MRI + *FBN1* |
| 矮小 + 蹼頸 + 下斜眼裂 | **Noonan** | Echo (PS/HCM) + *PTPN11* |
| 矮小 + 蹼頸 + 盾狀胸（女性） | **Turner** | Karyotype + Echo |
| 精靈面容 + 過度友善 | **Williams** | Echo (SVAS) + FISH 7q11.23 |
| 長臉 + 鼻音 + 低血鈣 | **22q11.2 del** | Echo + FISH 22q11.2 |
| 眼距過寬 + 雙叉懸雍垂 | **Loeys-Dietz** | CTA 全動脈 + *TGFBR1/2* |
| 多發性雀斑 | **LEOPARD** | Echo (HCM) + *PTPN11* |

# 表型導向的心臟篩檢（續）

| 看到什麼 | 想到什麼 | 做什麼 |
|---------|---------|---------|
| 三角臉 + 膽汁鬱積 + 蝴蝶椎 | **Alagille** | Echo (peripheral PS) + *JAG1* |
| 寬拇指/大腳趾 + 鷹勾鼻 | **Rubinstein-Taybi** | Echo + *CREBBP* |
| 小腿假性肥大 + Gowers' sign | **Duchenne** | ECG + Echo + CK + *DMD* |
| 肌強直 + 前額禿 + 白內障 | **DM1** | ECG + **Holter** + *DMPK* |
| 早期攣縮 + 肌無力 | **Emery-Dreifuss** | ECG + Holter + *EMD/LMNA* |
| 進行性共濟失調 + 弓形足 | **Friedreich** | Echo (HCM) + *FXN* |

# 速記口訣

```text
骨骼看心臟：               肌肉看心臟：
  拇指異常 → ASD              小腿肥大 → DCM
  蜘蛛指   → 主動脈            前額禿   → 傳導異常
  寬拇指   → 中隔缺損           早期攣縮 → AV block
  多指     → 單心房             共濟失調 → HCM

面容看心臟：
  精靈臉   → SVAS
  長臉鼻音 → TOF
  三角臉   → peripheral PS
  雀斑     → HCM
```

---

# Take-Home Messages

1. 心臟與四肢、面容**共享基因調控路徑** — 外觀異常是心臟病的窗口
2. Holt-Oram (TBX5)：**ASD + 橈側上肢缺損**，~60% de novo
3. Holt-Oram 患者**心導管前務必評估上肢血管**
4. 結締組織疾病各有獨特線索：**水晶體脫位** (Marfan)、**雙叉懸雍垂** (Loeys-Dietz)、**透明皮膚** (vascular EDS)
5. 神經肌肉疾病心臟併發症是**主要致死原因** — DM1 和 LMNA 猝死風險最高
6. **看見外表，想到心臟** → 多專科團隊合作
