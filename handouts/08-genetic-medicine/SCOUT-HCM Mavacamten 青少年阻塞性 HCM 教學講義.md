## 核心發現摘要

> **重大發現**：在症狀性青少年（12 至 <18 歲）阻塞性肥厚型心肌病（obstructive hypertrophic cardiomyopathy, HCM）患者中，心肌肌凝蛋白抑制劑（cardiac myosin inhibitor）**mavacamten** 於第 28 週使 Valsalva 誘發 left ventricular outflow tract (LVOT) gradient 降低 **−48.5 mmHg**，顯著優於安慰劑的 −0.5 mmHg（差 **−48.0 mmHg**；95% CI −67.7 至 −28.3；**P<0.001**）。
>
> **臨床意義**：這是**首個**在兒科族群針對 HCM 病理生理源頭（心肌過度收縮）進行的 phase 3 隨機對照試驗（randomized controlled trial, RCT）陽性結果。安全性與成人相近，28 週內無人 LVEF 降至 <50%、無死亡。惟樣本僅 n=44、追蹤僅 28 週、主要終點為生理性 gradient 而非硬臨床終點，且由藥廠資助，臨床外推仍需審慎。

## 2. 研究背景：兒童 HCM 的未滿足需求

- HCM 是**最常見的遺傳性心血管疾病**，以左心室肥厚為主要特徵（在無其他心臟、系統性或代謝疾病的前提下）。
- **LVOT obstruction**（靜息或誘發 gradient ≥30 mmHg）常見，可導致嚴重症狀甚至心衰竭；並常合併舒張功能不良、二尖瓣逆流（mitral regurgitation, MR）與自律神經功能異常。
- **兒童 HCM 為罕見病**，盛行率約 3–9/100,000 兒童，但預後較成人型更差：致命性心律不整風險較高，心臟移植或猝死（sudden cardiac death, SCD）風險約為成人型的兩倍。
- **無任何藥物**經 FDA 或 EMA 核准用於兒童 HCM。現行藥物（beta-blocker、非二氫吡啶類 calcium-channel blocker、disopyramide）皆自成人資料外推，且**僅能緩解症狀**，無法針對病因。
- 約 **7–23%** 的兒科患者需接受外科心肌切除術（surgical myectomy）以緩解 LVOT obstruction。
- **Mavacamten** 為選擇性、心臟專一的 myosin inhibitor，已核准用於成人症狀性 NYHA II/III 阻塞性 HCM，並在 5 項成人 phase 3 試驗證實療效與安全性；但先前**未曾在兒科族群進行臨床評估**（僅在兒科病人來源的 iPSC 衍生心肌細胞證實有效）。

> **研究目標**：評估 mavacamten 相較於安慰劑，在症狀性青少年（12 至 <18 歲）阻塞性 HCM 患者的療效與安全性。

## 3. 研究方法

### 研究設計

- **研究類型**：Phase 3、雙盲、隨機、安慰劑對照試驗（含 active-treatment 與 long-term extension 期，本文報告雙盲期結果）
- **收案期間**：2024 年 4 月至 2025 年 4 月，橫跨 **9 國、28 個中心**
- **雙盲期**：Baseline 至第 28 週；資料鎖定日 2025-11-25
- **隨機分配**：1:1，依年齡（12 至 <15 歲 / 15 至 <18 歲）與 beta-blocker 使用（有/無）分層
- **分析原則**：Intention-to-treat（treatment policy estimand）；主要終點採 mixed-effect model for repeated measures (MMRM)

### 納入與排除條件

| 類型 | 標準 |
|------|------|
| **納入條件** | 12 至 <18 歲；HCM 診斷（最大左室壁厚 ≥15 mm，或有家族史/致病基因變異時 ≥13 mm，或超音波肥厚 ≥2 SD）；Valsalva LVOT gradient ≥30 mmHg；最大 LVOT gradient（靜息、Valsalva 或運動後）≥50 mmHg；LVEF ≥60%；NYHA II 或 III |
| **排除條件** | HCM phenocopy（如 Noonan syndrome、Fabry disease） |

### 給藥方式（Dosing）

```text
起始劑量（依體重）：
  體重 ≥45 kg  → mavacamten 5 mg QD
  體重 35–<45 kg → mavacamten 2.5 mg QD
        |
劑量調整（依 echo 之 Valsalva LVOT gradient 與 LVEF）：
  減量：第 5、9 週可下調一級
  加量：第 12、24 週可上調一級
        |
可用劑量階梯：1 / 2.5 / 5 / 10 / 15 mg
```

- 允許維持背景 HCM 藥物（beta-blocker、CCB、disopyramide），需於篩選前穩定劑量 ≥14 天。
- 91% mavacamten 組以 5 mg 起始；全部 23 位服藥者劑量順從度 ≥80%。

### 終點（End Points）

- **主要終點**：Baseline 至第 28 週 **Valsalva 誘發 LVOT gradient** 的變化。
- **次要療效終點**：靜息與運動後 LVOT gradient、最大左室壁厚、E/e′ ratio、HCMSQ 呼吸困難（Shortness-of-Breath, SoB）分數；以及 peak VO₂ 上升比例、gradient 降至 <30 mmHg 比例、NYHA 改善 ≥1 級、MR 改善 ≥1 級。
- **探索性終點**：NT-proBNP、hs-cardiac troponin I/T 變化。
- **安全性終點**：不良事件（adverse events, AE）、嚴重不良事件（serious adverse events, SAE）、LVEF 降至 <50% 或 ≤30%、QT 間期（Fridericia 校正）變化。

## 4. 主要結果：療效

### 基線特徵（Baseline Characteristics）

| 特徵 | Mavacamten (n=23) | Placebo (n=21) |
|------|-------------------|----------------|
| 年齡（歲） | 14.7 ± 1.7 | 14.6 ± 1.7 |
| 女性 | 8 (35%) | 5 (24%) |
| 體重（kg） | 71.1 ± 19.1 | 67.4 ± 18.6 |
| 致病/可能致病基因變異 | 12 (52%) | 12 (57%) |
| Beta-blocker 使用 | 19 (83%) | 18 (86%) |
| NYHA II / III | 19 (83%) / 4 (17%) | 18 (86%) / 3 (14%) |
| **Valsalva LVOT gradient（mmHg）** | **78.4 ± 34.1** | **80.8 ± 47.4** |
| 靜息 LVOT gradient（mmHg） | 64.8 ± 30.9 | 65.2 ± 38.1 |
| LVEF（%） | 69.0 ± 3.9 | 67.4 ± 4.1 |
| 最大左室壁厚（mm） | 28.3 ± 6.0 | 24.7 ± 7.1 |
| 中位 NT-proBNP（pg/mL） | 1776 | 1294 |

> 兩組大致平衡；mavacamten 組在 BMI、NT-proBNP、hs-cTnI 略高。相較成人 EXPLORER-HCM，SCOUT-HCM 族群 gradient、壁厚、生物標記皆更高，代表**疾病更嚴重**。

### 主要與次要終點（第 28 週變化）

| 終點 | Mavacamten LS mean change | Placebo LS mean change | 對安慰劑差值 (95% CI) |
|------|----------------------------|-------------------------|------------------------|
| **Valsalva LVOT gradient（mmHg）★主要** | **−48.5** (−63.0 至 −34.0) | **−0.5** (−18.7 至 17.6) | **−48.0 (−67.7 至 −28.3)；P<0.001** |
| 靜息 LVOT gradient（mmHg） | −39.0 | +8.1 | −47.0 (−62.7 至 −31.4) |
| 運動後 LVOT gradient（mmHg） | −31.2 | +10.5 | −41.7 (−59.7 至 −23.7) |
| 最大左室壁厚（mm） | −2.5 | −0.7 | −1.8 (−3.4 至 −0.2) |
| E/e′ ratio（平均） | −3.7 | −0.4 | −3.4 (−5.1 至 −1.6) |
| HCMSQ SoB 分數（點） | −1.1 | −0.8 | −0.3 (−2.0 至 1.5) |

- Mavacamten 組 Valsalva gradient 由 78.4 → **29.0 mmHg**；placebo 由 80.8 → 72.7 mmHg。
- **注意**：次要終點的 CI **未校正多重性**，僅供描述、不可視為正式假設檢定。HCMSQ SoB 兩組差異不顯著（信賴區間跨 0）。

### 探索性生物標記（第 28 週相對 baseline 之組間幾何平均比 GMR）

| 生物標記 | GMR（Mava/Placebo） | 95% CI |
|----------|---------------------|--------|
| NT-proBNP | 0.23 | 0.14–0.37 |
| hs-cardiac troponin I | 0.37 | 0.23–0.60 |
| hs-cardiac troponin T | 0.55 | 0.38–0.79 |

- Peak VO₂ 上升比例：mavacamten 73% vs placebo 44%（風險差 29.6 個百分點，95% CI −5.7 至 58.3，**跨 0**）。

## 5. 主要結果：安全性

| 安全性事件 | Mavacamten (n=23) | Placebo (n=21) |
|------------|-------------------|----------------|
| 任何 AE | 18 (78%) | 17 (81%) |
| 治療相關 AE | 2 (9%) | 3 (14%) |
| 任何 SAE | 2 (9%) | 2 (10%) |
| 導致治療中斷之 AE | 1 (4%) | 1 (5%) |
| 導致停藥之 AE | 0 | 0 |
| 死亡 | 0 | 0 |
| LVEF 降至 <50% | 0 | 0 |
| LVEF 降至 ≤30% | 0 | 0 |

### 嚴重不良事件細節

- **Mavacamten 組（2 例）**：1 例兩次 syncope（發生於有 presyncope 病史者，經研究者判定與 mavacamten 相關，患者續用且無再發）；1 例 implantable cardioverter–defibrillator (ICD) 不適當放電（判定與 mavacamten 無關，但住院期間暫時中斷治療）。
- **Placebo 組（2 例）**：1 例胸痛；1 例憂鬱合併自殺意念。

### 其他安全性

- QT 間期（Fridericia 校正）第 28 週變化：mavacamten **−12.9 ± 5.6 ms** vs placebo **+9.3 ± 5.5 ms**。
- **無人 LVEF 降至 <50%，無死亡**——這是 myosin inhibitor 在兒科最受關注的安全訊號，本試驗未出現。

## 6. 討論與臨床意義

### 重要發現

1. **首個兒科陽性 RCT**：Mavacamten 顯著降低青少年阻塞性 HCM 的 Valsalva LVOT gradient，且多項次要與探索性終點（靜息/運動後 gradient、壁厚、E/e′、NYHA、MR、NT-proBNP、troponin）方向一致支持主要結果。
2. **直接針對病因**：不同於既有僅緩解症狀的藥物，myosin inhibitor 針對心肌過度收縮（hypercontractility）此一疾病源頭，可能改變兒科 HCM 的治療典範。
3. **與成人資料一致**：療效與安全性與 5 項成人 phase 3 試驗（如 EXPLORER-HCM、VALOR-HCM）方向一致；且 SCOUT-HCM 族群疾病更嚴重、基因陽性比例更高。
4. **可能的長期意涵**：兒科 HCM 表現型較侵襲性，於成年前介入或有機會改善日後臨床結局，但仍待長期資料（試驗 active-treatment 與 extension 期共約 3 年）驗證。

### 臨床實務建議

> **重點提醒**：本試驗為青少年阻塞性 HCM 提供了**針對病因**的藥物證據，且短期安全性令人安心（無 LVEF <50%、無死亡）。然而，主要終點為**影像學 gradient** 而非症狀或硬終點；症狀量表（HCMSQ SoB）**未見顯著改善**，且該量表在青少年尚未驗證。臨床應用前，仍應等待更長期、涵蓋更廣兒科族群與經驗證病人報告結局的資料。

---

## 7. 研究限制

1. **樣本數小（n=44）**：因兒童/青少年 HCM 盛行率低，樣本小，無法深入分析次要與探索性終點，也無法依性別或其他次族群分層。
2. **追蹤期短（僅 28 週）**：無法評估長期療效與安全性；hypercontractility 反轉是否持久待 extension 期資料。
3. **主要終點為生理性 gradient**：以 Valsalva LVOT gradient 為主要終點，並非症狀或硬臨床終點（住院、死亡、移植、SCD）；症狀量表未達顯著。
4. **族群以白人為主**：雖較 EXPLORER-HCM 更多元，仍以白人為主。
5. **未涵蓋 <12 歲兒童**：需要更廣兒科族群（含 <12 歲）與更長期研究。
6. **藥廠資助且參與分析**：試驗由 Bristol Myers Squibb 設計、資料由藥廠分析、寫作支援由藥廠資助，潛在利益衝突需納入考量。

---

## 8. 結論

1. 在症狀性青少年（12 至 <18 歲）阻塞性 HCM 患者中，mavacamten 於 28 週內降低 Valsalva LVOT gradient 的效果**顯著優於安慰劑**（差 −48.0 mmHg；P<0.001）。
2. 安全性與成人相近，**無新安全訊號**：無人 LVEF <50%、無死亡。
3. 這是兒科 HCM 首個針對病因治療的 phase 3 陽性結果，惟受限於**小樣本、短追蹤、生理性主要終點與藥廠資助**，臨床外推須審慎，並待長期與更廣族群資料。
