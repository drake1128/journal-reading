# Never Miss a Ventricular Septal Defect on Echo / 不要漏掉半個 VSD：心臟超音波的技術與判讀

## 先講三個結論

1. **2D 看不到，不等於沒有。** Smyllie 兩個 post-MI 系列：2D 直接看到破口的只有 35% 與 40%，加上 colour flow mapping 後 100% 抓到 [6,7]。Ortiz 23 例未開刀 VSD，11 例小到 2D 看不見，全靠 colour 找到 [4]。
2. **漏診多半「可預防」，而且是系統問題。** Boston Children's 系列：77% 可預防或可能可預防；夜間判讀 (AOR 2.6) 與週末檢查 (AOR 1.6) 是獨立危險因子 [14,15]。2025 年 14 中心 1,476 例：錯誤率 7.1%，74% 可預防；認知因素 43%、影像因素 47%；心室中隔名列前 80% 的關鍵解剖部位 [16]。
3. **成人標準 protocol 本身有一個洞。** ASE 2019 成人全面性 TTE 指引的 colour Doppler 章節列出 RVOT、TV、MV、AV、主動脈弓、肺靜脈、肝靜脈、IVC、心房中隔，卻沒有「心室中隔」專節 [1]。這一步得自己補上。

## 一、為什麼會漏？五個機轉

1. **破口不在標準切面上。** Perimembranous 常被 tricuspid 組織蓋住；muscular 可在任何位置、可多發；doubly committed 要 PLAX 逆時針微轉或 PSAX 12–2 點 [2]。Post-MI 破口蛇行，入口出口不同平面 [9,11]。
2. **Colour 設定是給瓣膜用的。** 常規 Nyquist 50–70 cm/s [1]；非限制型、肺高壓時 jet 低速。Sutherland 多發 VSD 系列：colour 限制型 89% vs 非限制型 62% [5]。Gain 調到 speckle 再退回 [1]。
3. **只掃切面，沒有 sweep。** "The septum should be interrogated thoroughly at its entire length by sweeping from subcostal, apical and parasternal views" [2]。CASE 2024：VSR 後面藏著先天 VSD，術中 TEE 才發現 [12]。
4. **認知因素。** 43% 可預防錯誤來自認知因素 [16]：沒看轉診目的、沒聽心音、沒注意 post-MI 第 2–7 天的新 murmur。
5. **長得像別的東西。** Gerbode 被當成 TR + PH：TTE 正確 62.2%、漏診 9.8%、誤診 14.5% [17,18]。反之 double-chambered LV、LV diverticulum 被誤判為 VSD [19,20]。

## 二、技術：七步驟

| 步驟 | 做法與依據 |
|---|---|
| 1. 掃之前先想 | 轉診目的、心音。高風險：post-MI 新 murmur／惡化 [9,10]、不明 LA/LV 擴大、不明 PH、AR + RCC prolapse、IE、瓣膜手術／TAVI 後 [2,30,31] |
| 2. 2D sweep 整條中隔 | PSAX 從 AV 掃到 apex；A4C 後→前到 5C；subcostal；PLAX 逆時針看 outlet [2]。Anterior MI 找 apical septum，inferior MI 找 basal inferior septum，找第二個破口 [6,9] |
| 3. Colour 再 sweep | Box 窄、frame rate 高。先 50–70，再降 30–40 cm/s；gain 到 speckle 再退 [1]。PSAX AV 層：9–11 點 perimembranous、12–2 點 doubly committed；往 apex：anterior 12–2、mid 10–12、posterior 7–10 [2] |
| 4. CW 放在 jet 上 | Holosystolic 高速 = 限制型；由 jet 估 RV 壓 [2]；與 TR 區分。Post-MI RV 內 systolic flow disturbance 即線索 [7] |
| 5. 間接證據 | LA/LV 擴大無 MR/AR 可解釋 [2,24]；AR + RCC prolapse → outlet VSD（亞洲常見）[26,27]；RVOT 高速 → DCRV；RA 高速 jet → Gerbode [2,17]；Qp/Qs 對直徑誤差敏感 [2] |
| 6. 不確定就升級 | Post-MI TTE 不清 → TEE [8,9]；3D en face [21,22]；CMR／CT／導管 [17,28,29] |
| 7. 報告寫清楚 | 「IVS colour sweep 無分流」明寫；沒掃到就寫沒掃到；標準化 protocol 與結構化報告 [3] |

## 三、判讀：三種最容易漏的情境

- **(a) Post-MI VSR。** 發生率約 0.2%，不手術一個月存活 6% [10]。AHA 2021：立刻、床邊、含 colour 與 spectral Doppler；TTE 不清就 TEE [9]。時間窗 2–7 天；也有延遲兩個月才表現者 [13]。
- **(b) 成人先天性 VSD。** 佔先天心臟病近四成 [24,25]。Outlet VSD 的 aortic cusp prolapse 在亞洲比例高：台大 677 例 outlet VSD 手術系列 [26]、JACC Asia 2026 大型亞洲系列 [27]。分類用 ICD-11 國際共識 [23]。
- **(c) Gerbode 與醫源性 VSD。** IE、MVR、TAVI 後 [17,30,31]。RA 高速 jet 起點不像 TV、TR gradient 高到不合理、無其他 PH 證據 → 想 Gerbode。

## 四、制度建議

1. Protocol 加一行「IVS colour sweep：PSAX、A4C、subcostal」，報告模板加欄位 [1,3]。
2. 高風險情境自動觸發低 Nyquist 中隔 sweep [2,9]。
3. 夜間與週末檢查隔日第二位醫師複讀 [15]。
4. 診斷錯誤分類與回饋（嚴重度、可預防性、貢獻因素），改流程不究責 [14,16]。

> **總結一句**：看到 VSD 靠的不是眼睛，是每一次都把中隔從頭掃到尾的習慣。
