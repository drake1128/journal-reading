# Severe Valve Deformation Following CPR in TAVR
## TAVR 術後 CPR 致瓣膜嚴重變形
**謝慕揚 MD, PhD, FESC** | 2026-04-05
[JACC Cardiovasc Interv. 2015;8(3):498-499](https://doi.org/10.1016/j.jcin.2014.10.023)

---

# 病例簡介

| 項目 | 內容 |
|------|------|
| 年齡 | 87 歲 |
| 診斷 | Severe aortic stenosis |
| 手術方式 | **Transapical** TAVR |
| 瓣膜 | 26-mm Edwards SAPIEN |
| Annulus area (CT) | 430 mm² |
| Oversizing | 23% |

### 術前關鍵發現
- LVOT **嚴重不對稱鈣化** (posterolateral aspect)
- 累及 intravalvular fibrous curtain

---

# 手術過程

## 瓣膜置放
- 展開位置適當
- LVOT 鈣化處出現 **moderate paravalvular regurgitation**

## Post-dilation
- Delivery balloon 加注 1 mL 再擴張
- PVL 略為減少

> **LVOT 嚴重不對稱鈣化** = paravalvular leak 的重要危險因子

---

# 術後經過

## 恢復期
- 病人恢復良好
- 輕微心衰竭症狀

## Hospital Day 4
- 發生 **cardiac arrest**
- 施行 **48 分鐘 CPR**
- **未恢復自發性循環** (no ROSC)

# 屍檢發現

---

# 瓣膜被壓扁

## Autopsy 發現
- SAPIEN valve **被壓扁 (crushed)**
- 變形位置：**LVOT 鈣化處**
- 瓣膜框架嚴重扭曲

## Postmortem radiograph
- LVOT calcium 使瓣膜框架變形
- 鈣化充當壓扁瓣膜的「**支點**」

> 瓣膜嚴重變形 → leaflet coaptation 喪失 → 復甦不可能成功

---

# 致死機轉

```text
CPR 胸外按壓
        |
胸骨壓迫力傳至心臟
        |
LVOT 鈣化充當「支點」(fulcrum)
        |
Balloon-expandable valve frame 被壓扁
        |
Leaflet coaptation 嚴重受損
        |
瓣膜功能完全喪失 → 復甦失敗
```

> **LVOT 鈣化的雙重角色**：術中 → PVL；CPR 時 → 瓣膜壓扁的支點

# Balloon-expandable vs. Self-expandable

| 特性 | Balloon-expandable | Self-expandable |
|------|-------------------|----------------|
| 代表 | SAPIEN | CoreValve / Evolut |
| 框架材質 | Cobalt-chromium | Nitinol |
| 徑向力 | 較低 | 較高（持續向外施力） |
| **CPR 變形風險** | **較高** | 理論上較低 |
| 恢復形狀 | **無法** | Nitinol shape memory |

> Self-expandable valve 的 nitinol 框架理論上較能抵抗 CPR 壓力，但缺乏臨床證據

---

# Take Home Messages

> **1.** Balloon-expandable transcatheter valve 在 CPR 下 **可能被壓扁**，導致瓣膜功能喪失、復甦失敗

> **2.** LVOT 嚴重不對稱鈣化是 **雙重危險因子**：增加 PVL 風險 + 增加 CPR 時瓣膜變形風險

> **3.** TAVR 病人 CPR 後存活者，**必須進行影像學評估** 確認瓣膜完整性

> **4.** LVOT 嚴重鈣化時，可考慮 self-expandable valve（nitinol shape memory），但目前無臨床證據

---

# CPR 後評估建議

| 評估項目 | 方法 |
|---------|------|
| 瓣膜形態 | Echocardiography |
| 新出現 AR | Color Doppler |
| 框架圓形度 | CT |
| 瓣葉活動 | TEE / Fluoroscopy |

- 注意新出現或惡化的 **aortic regurgitation**
- 評估瓣膜框架 **circularity** 有無變化
