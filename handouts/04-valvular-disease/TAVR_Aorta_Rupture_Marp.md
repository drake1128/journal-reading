# Descending Aorta Rupture During TAVR
## TAVR 術中降主動脈破裂
**謝慕揚 MD, PhD, FESC** | 2026-04-05
[Circulation. 2016;133:e14-e17](https://doi.org/10.1161/CIRCULATIONAHA.115.019824)

---

# 病例簡介

| 項目 | 內容 |
|------|------|
| 年齡/性別 | 88 歲女性 |
| 病史 | 永久性 VDD pacemaker |
| 診斷 | Severe aortic stenosis |
| AVA / Mean gradient | 0.5 cm² / 86 mmHg |
| LVEF | 64% |
| Annulus (TEE / MDCT) | 23.5 / 23.7 mm |
| Logistic EuroSCORE | **35.3%**（高手術風險） |

---

# 術前 CT：主動脈解剖

## 關鍵發現

- 股髂動脈：走行筆直、輕度鈣化、內徑足夠
- **主動脈嚴重迂曲 (great tortuosity)**
  - Descending thoracic aorta → **double angle**
  - Distal aortic arch → **very pronounced curve**

> **Warning sign**: 嚴重主動脈迂曲是 transfemoral TAVR 血管併發症的重要危險因子

---

<!-- _class: divider -->
# 手術過程與併發症

---

# 手術策略與併發症發生

## 入路與器材選擇
- **Right transfemoral access** + percutaneous closure device
- **Self-expandable 29-mm CoreValve** (Medtronic)

## 事件經過
1. Delivery system 在 **distal aortic arch** 遇到高度阻力
2. 強行推進 → delivery system 在 descending aorta **第一角度處彎折**
3. 角度惡化 (kinking worsened)
4. **急性血流動力學崩潰** (acute hemodynamic collapse)

---

# 破裂機轉

```text
Aortic arch acute angle
    → 阻力傳遞至 delivery system
        → Descending aorta proximal angle 處 kinking
            → 主動脈壁外緣撕裂
                → Acute hemodynamic collapse
```

> **Key**: 破裂發生在 delivery system 彎折處——descending aorta **proximal angle 的外緣 (external edge)**

---

# 影像診斷

| 影像模式 | 發現 |
|---------|------|
| Fluoroscopy | Delivery system 在 descending aorta 角度處彎折 |
| **Aortography** | Descending thoracic aorta **contrast extravasation** |
| TEE 2D | 前壁主動脈壁破裂 |
| TEE Color Doppler | Systolic flow 穿越破裂處 |
| TEE 3D | 主動脈壁撕裂 |

> TEE 是偵測 TAVR 術中血管併發症的重要工具

---

<!-- _class: divider -->
# 急救處理

---

# Bailout 策略

## Step 1: 止血
- **Occlusive balloon**: 250-mm valvuloplasty balloon 充氣於 left subclavian take-off 遠端
- 經同一股動脈入路操作

## Step 2: Stent graft
- **31×15 mm Gore TAG** stent graft 覆蓋漏血處
- Aortography 確認無 endoleak
- 血流動力學暫時改善

## Step 3: 瓣膜置換
- 改用 **26-mm SAPIEN 3** (balloon-expandable) 成功植入

---

# 臨床結局

## 術後狀況
- TEE 發現 **大量雙側血胸** (large bilateral hemothorax)
- 放置胸管引流、輸血

## 最終結局
- 儘管積極輸液 + 高劑量 inotropes + vasoconstrictors
- **2 小時後死於 refractory hypovolemic shock**

## 屍檢
- Descending aorta proximal angle 外緣 → **大面積主動脈壁撕裂**
- 撕裂處被 stent graft 覆蓋
- 大量血胸

# 教學重點

---

# 教學要點

## Descending aorta rupture 特點
- TAVR 術中 **極為罕見** 的致命併發症
- **幾乎必然致命** (almost invariably lethal)
- 懷疑時機：catheter 推進中出現 **無法解釋的低血壓**

## 危險因子

| 危險因子 | 說明 |
|---------|------|
| 主動脈嚴重迂曲 | Double angle, pronounced curve |
| Aortic arch 急角度 | 阻力傳遞至 delivery system |
| Large-bore delivery catheter | Self-expandable valve 尤其明顯 |
| 高齡血管脆弱 | 血管壁承受力下降 |

---

# Take Home Messages

> **1.** 術前 CT 必須評估 **整條血管路徑** 的角度與迂曲程度，不僅是股髂動脈

> **2.** Delivery system 推進遇到阻力時 **不應強行推進**，應考慮更換入路或器材

> **3.** Self-expandable valve delivery system 較大較硬，嚴重迂曲時 balloon-expandable 可能更安全

> **4.** 術中應備有 **occlusive balloon** 與 **covered stent graft** 以應對血管破裂

---

# 預防策略

| 策略 | 具體做法 |
|------|---------|
| **Patient selection** | 依個案評估 benefit-risk ratio |
| **Access route** | 嚴重迂曲考慮 transapical / transaortic / transsubclavian |
| **Device selection** | 選擇較小 profile 或較軟的 delivery system |
| **Bailout 準備** | 預先備妥 occlusive balloon、covered stent graft |
