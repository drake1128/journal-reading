# Part 1
## 核心觀念與診斷流程

---

# 核心觀念：HFpEF 是排除性診斷

- 2021 通用定義：**症狀／徵象 + LVEF ≥ 50% + 充填壓上升的客觀證據**
- **不是「EF 正常的心衰竭都算 HFpEF」**
- 必須先排除有 **特定病因、且通常可治療** 的疾病

> 把瓣膜病、類澱粉、縮窄性心包炎當成 HFpEF，是最常見也最可惜的錯誤——因為這些都有**專屬治療**（修瓣、tafamidis、心包剝離）。

---

# H₂FPEF Score（Reddy / Borlaug 2018）

| 項目 | 內容 | 分數 |
|------|------|------|
| **H**eavy | BMI > 30 kg/m² | 2 |
| **H**ypertensive | ≥ 2 種降壓藥 | 1 |
| **F**ibrillation | 心房顫動 | 3 |
| **P**ulmonary HTN | PASP > 35 mmHg | 1 |
| **E**lder | 年齡 > 60 | 1 |
| **F**illing pressure | E/e′ > 9 | 1 |

- **0–1**：低機率（rule out）｜**2–5**：中間 → 進一步檢查｜**6–9**：高機率（rule in）

---

# HFA-PEFF Score（ESC/HFA 2019）

- **P** — Pretest：症狀、共病、ECG、基本 echo
- **E** — Echo + 利鈉胜肽：功能 / 形態 / 生物標記三面向；**主要 2 分、次要 1 分 → ≥5 分確診**，2–4 分需進一步
- **F** — Functional：**舒張壓力測試 / 侵入性運動血流動力學**
- **F** — Final：找特定病因（**本講義重點**）

> ⚠️ 兩套分數對同一病人**常不一致（discordance）**，落在中間區間時尤甚——不要把單一分數當絕對標準。

# Part 2
## 診斷陷阱總覽

---

# 會偽裝成 HFpEF 的疾病

| 陷阱 | 鑑別關鍵 | 為什麼重要 |
|------|---------|-----------|
| **瓣膜病**（AS、原發 MR、TR） | 超音波瓣膜評估 | 治療是修瓣 |
| **心臟類澱粉（ATTR / AL）** | 低電壓 ECG、PYP 掃描 | tafamidis 可治 |
| **HCM / Fabry / sarcoidosis** | CMR、基因、酵素 | 各有專屬處置 |
| **縮窄性心包炎** | septal bounce、心包鈣化 | 手術可治癒 |
| **高輸出心衰** | 貧血 / 甲亢 / AV fistula | 治根本病因 |
| **前微血管 PH（PAH / CTEPH）** | RHC：PCWP 正常、PVR 高 | 標靶 / 手術 |

---

<!-- _class: divider -->
# Part 3
## 重點：與瓣膜病鑑別（AS / MR）

---

# Severe AS / MR 算不算 HFpEF？

| 情況 | 算 HFpEF？ | 處置 |
|------|-----------|------|
| **Severe AS** | ❌ 不是 → valvular HF | TAVR / SAVR |
| **原發 / 器質性 MR**（瓣葉病變、脫垂） | ❌ 不是 → valvular HF | 修瓣（surgery / TEER） |
| **次發 / 心房性功能性 MR（AFMR）** | ✅ HFpEF 的**後果**，可共存 | 處理 HFpEF / AF / 容積 |

> **原發瓣膜病 = HFpEF 的「病因」要排除；功能性／心房性 MR = HFpEF 的「後果」可並存。**

---

# 三個結構介入醫師要記的重疊陷阱

- **Paradoxical LFLG AS**：小腔室、向心肥厚、僵硬 LV — 正是 HFpEF 表現型；EF ≥ 50% 但每搏輸出低 → 壓差被低估，仍是重度 AS
- **AS + ATTR 雙病理**：老年低流量低壓差 AS，類澱粉共存約 **1/8** — TAVR 術前要警覺
- **EF 假性偏高**：重度 MR 大量逆流 → LVEF 數值看似正常，**前向輸出其實已降** → 別被 EF 騙

> 看到 MR 先問：**瓣葉有沒有病變？** 器質性 → valvular HF；功能性 → 可能是 HFpEF 表徵

---

<!-- _class: divider -->
# Part 4
## 心臟類澱粉與其他可治病因

---

# 心臟類澱粉（ATTR）— 最該主動篩的「可治 HFpEF」

- 在 HFpEF 中盛行率約 **6–14%**（老年 + LV 壁厚 ≥ 12 mm 約 13%）
- **紅旗**：不成比例向心 LVH、**ECG 低電壓 / 電壓-質量不相稱**、**雙側腕隧道症候群**（早於心臟症狀數年）、對 ACEi/β-blocker 異常不耐
- **診斷**：先排除 AL（免疫固定電泳 + free light chain）→ ATTR 用 **⁹⁹ᵐTc-PYP/DPD 掃描**（Perugini 2–3）非侵入確診
- **重要性**：有疾病修飾藥（tafamidis 等）

---

# 其他可治的「偽 HFpEF」

- **HCM / Fabry / sarcoidosis / hemochromatosis** → CMR（LGE、T1/ECV）、基因、酵素
- **縮窄性心包炎** → 呼吸相依的心室交互依存、**septal bounce**、心包增厚 / 鈣化；**心包剝離可治癒**
- **高輸出心衰** → 貧血、甲亢、AV fistula、肝病
- **前微血管 PH** → RHC 鑑別：HFpEF 為後微血管型（**PCWP > 15**），前微血管型 PCWP 正常、**PVR 升高**

---

<!-- _class: divider -->
# Part 5
## 生物標記與影像陷阱

---

# 利鈉胜肽（BNP / NT-proBNP）陷阱

- **可以是正常的，尤其肥胖病人** — 脂肪壓低利鈉胜肽 → **正常 BNP 不能排除 HFpEF**
- **AF 會拉高** → 需用較高閾值（HFA-PEFF：NT-proBNP SR > 220、AF > 660 pg/mL）
- **腎功能差、高齡** 亦升高 → 偽陽性

> 肥胖 + BNP 正常 + 運動喘 ≠ 沒有 HFpEF

---

# EF 與影像陷阱

- **EF 保留 ≠ 收縮正常**：GLS（整體縱向應變）常已受損
- **重度 MR 使 EF 假性偏高**（前向輸出已降）
- **舒張分級不完美**：E/e′、LAVI、TR velocity 各有侷限；LA 大可能是 AF 而非充填壓
- **靜態正常不能排除** → 需 **運動誘發**：diastolic stress echo 或 **侵入性運動 PCWP** 來 unmask

---

# 一頁式診斷流程（Decision Flow）

```text
HF 症狀/徵象 + LVEF ≥ 50%
   │
 [1] 利鈉胜肽 + 完整 echo（瓣膜、LV 壁厚、LA、TR、GLS）
   │
 [2] 先排除「特定可治病因」?
   ├ 重度 AS / 原發 MR / TR ────► 瓣膜性心衰竭 → 修瓣 (TAVR/SAVR/TEER)
   ├ 不對稱 LVH + 低電壓 + 腕隧道 ─► 疑類澱粉 → PYP 掃描 (tafamidis)
   ├ septal bounce + 心包鈣化 ───► 縮窄性心包炎 → 心包剝離
   ├ RHC：PCWP 正常 + PVR 高 ────► 前微血管 PH → 標靶/手術
   └ 貧血 / 甲亢 / AV fistula ───► 高輸出心衰 → 治根本
   │ （皆排除後）
 [3] 充填壓證據 (H₂FPEF / HFA-PEFF)
   ├ 高機率 (6–9 / ≥5) ─────────► 診斷 HFpEF
   ├ 中間 (2–5 / 2–4) ──────────► 運動誘發 (diastolic stress / 侵入 PCWP)
   └ 低機率 (0–1) ──────────────► 找其他原因 (CAD、肺、deconditioning)
```

> 診斷重心在 **Step 2（排除）**，不是急著在 Step 3 算分數。

---

# 臨床重點整理（Clinical Pearls）

> **Pearl 1**：HFpEF 是排除性診斷——先排除瓣膜病、類澱粉、縮窄、前微血管 PH。

> **Pearl 2**：Severe AS / 原發 MR 不是 HFpEF；**LFLG AS、AS+amyloid、AFMR** 是三個重疊陷阱。

> **Pearl 3**：肥胖 BNP 正常不能排除 HFpEF；AF 要用較高閾值。

> **Pearl 4**：老年 + 不對稱 LVH + ECG 低電壓 + 雙側腕隧道 → 篩 **ATTR**（PYP 掃描）。
