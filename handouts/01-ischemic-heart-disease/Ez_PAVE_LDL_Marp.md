# Ez-PAVE Trial
## LDL <55 vs <70 mg/dL 強化降脂於 ASCVD 次級預防

**謝慕揚 MD, PhD, FESC** | 2026-04-09

[NEJM 2026;394:1365-1375 — DOI 10.1056/NEJMoa2600283](https://doi.org/10.1056/NEJMoa2600283)

---

# 研究背景

- ESC/EAS 與 ACC 將 ASCVD 病人 LDL 目標由 **<70 → <55 mg/dL**
- 證據主要來自 IMPROVE-IT、FOURIER、ODYSSEY 等「藥物試驗」
- **直接比較兩個 LDL 目標的 RCT 極為缺乏**
- TST trial 對照組為 90–110 mg/dL，與當代指引脫節
- 臨床達標率仍不理想 → guideline–practice gap

> **研究問題**：ASCVD 病人，LDL <55 是否優於 <70 ？

---

# 試驗設計

| 項目 | 內容 |
|------|------|
| 設計 | Multicenter, **open-label superiority RCT** |
| 地點 | 南韓 17 中心 |
| N | **3048** (1:1) |
| 追蹤 | 中位 3.0 年 |
| Intensive | LDL **<55 mg/dL** (n=1526) |
| Conventional | LDL **<70 mg/dL** (n=1522) |
| 第二層隨機 | Statin 單藥 vs Statin + Ezetimibe；rosuvastatin vs atorvastatin |
| 治療策略 | 加 ezetimibe 優先於 PCSK9i |

**主要終點**：3 年 composite — CV death / nonfatal MI / nonfatal stroke / any revascularization / unstable angina hospitalization

---

# 病人特徵 (均衡)

| | Intensive | Conventional |
|---|---|---|
| Age | 64.2 ± 9.1 | 64.6 ± 9.0 |
| Male | 78.9% | 79.2% |
| Previous ACS | 54.2% | 57.0% |
| PCI | 57.9% | 59.1% |
| Diabetes | 39.6% | 39.6% |
| HTN | 74.4% | 72.5% |
| **Baseline LDL (median)** | **77 mg/dL** | **75 mg/dL** |
| 高強度 statin | 23.1% | 22.9% |
| Ezetimibe | 29.8% | 27.7% |

---

# LDL 達標情形

| | Intensive 中位 | Conventional 中位 |
|---|---|---|
| 試驗中位 LDL | **56 mg/dL** | **66 mg/dL** |

### 達標率（3 年）
- Intensive：**60.8% 達 <55**，**85.2% 達 <70**
- Conventional：**68.1% 達 <70**

### 3 年用藥
- 高強度 statin：**48.4% vs 32.3%**
- Ezetimibe：**66.6% vs 56.7%**
- PCSK9i：**2.3% vs 0.9%**（極少使用）

---

# 主要終點 — Intensive 勝出

| End Point | Intensive | Conventional | HR (95% CI) | P |
|-----------|-----------|--------------|-------------|---|
| **複合主要終點** | **6.6%** | **9.7%** | **0.67 (0.52–0.86)** | **0.002** |

> **3 年絕對風險下降 3.1 個百分點 (NNT ≈ 32)**

# 次要終點

| End Point | Intensive | Conventional | HR (95% CI) |
|-----------|-----------|--------------|-------------|
| CV death | 1.0% | 1.2% | 0.83 (0.42–1.65) |
| **Nonfatal MI** | **0.8%** | **1.7%** | **0.46 (0.23–0.91)** |
| Nonfatal stroke | 0.5% | 0.7% | 0.80 (0.32–2.03) |
| **Any revascularization** | **4.8%** | **7.5%** | **0.63 (0.47–0.84)** |
| PCI | 4.5% | 6.6% | 0.67 (0.49–0.91) |
| Unstable angina hosp. | 1.5% | 2.4% | 0.61 (0.36–1.03) |
| CV death/MI/stroke | 2.3% | 3.6% | 0.63 (0.41–0.96) |

> 益處主要來自 **MI ↓ 與 revascularization ↓**

---

# 安全性

| | Intensive | Conventional | P |
|---|---|---|---|
| New-onset DM | 16.6% | 16.1% | 0.81 |
| Worsening glycemic control | 48.8% | 50.7% | 0.55 |
| Statin myalgia → 改藥 | 1.0% | 0.6% | 0.31 |
| Cancer | 2.4% | 2.6% | 0.72 |
| AST/ALT ↑ | 2.4% | 1.5% | 0.09 |
| **Creatinine ↑ (>1.5×)** | **1.2%** | **2.7%** | **0.004** |
| CK ↑ | 0.3% | 0.3% | 1.00 |

> 兩組安全性相當；Intensive 組 creatinine 上升**反而較少**

---

# 子族群分析

主要終點 HR 大致一致偏向 intensive：

- Age <65：**0.56 (0.38–0.83)**
- Male：0.59 (0.45–0.79)
- Prior ACS：0.65 (0.43–0.97)
- **Diabetes：0.53 (0.36–0.78)**
- Baseline LDL <100：0.65 (0.48–0.87)
- Female (n=638)：1.22 (0.66–2.28) — 事件數少，難下結論

# Take Home Messages

---

# 臨床重點

> **Pearl 1**：ASCVD 病人 **LDL <55 優於 <70**（HR 0.67），3 年事件 NNT ≈ 32。

> **Pearl 2**：益處主要來自 **MI（HR 0.46）與 revascularization（HR 0.63）**。

> **Pearl 3**：**High-intensity statin + ezetimibe** 是達標主軸，**>97% 病人無需 PCSK9i**。

> **Pearl 4**：安全性無虞，肌肉、肝、新發糖尿病皆無差異。

> **Pearl 5**：對 ACS/PCI 後病人，**出院時即應以 <55 為目標規劃用藥**。

---

# 限制

- Open-label 設計（事件 committee 盲化判讀）
- 全為韓國人族群
- 中位追蹤 3 年，長期硬性終點待驗證
- Intensive 組僅 60.8% 達 <55 → 部分益處可能來自整體 LDL 曲線下降
