# 失智症合併心血管疾病照護
## Cardiovascular Risk Management in Persons with Dementia
**謝慕揚 MD, PhD, FESC** | 2026-04-08

| 項目 | 內容 |
|------|------|
| Journal | *J Alzheimers Dis* 2023 |
| DOI | [10.3233/JAD-230019](https://doi.org/10.3233/JAD-230019) |
| PMID | [37125555](https://pubmed.ncbi.nlm.nih.gov/37125555/) |

> 失智病人在現行 CVRM 指引中被排除，但 atherosclerotic disease 風險更高。**Survival time is significantly shorter in persons with dementia** → 須先評估預期餘命再啟動預防治療。

---

# 主文獻核心訊息

1. **證據空白**：無 RCT 專門針對失智族群評估 CV 介入
2. **血壓兩難**：低 daytime SBP 與認知退化相關 → 過度降壓有害
3. **競爭風險**：失智本身死亡風險高於 CV 事件 → risk calculator 失準
4. **用藥安全**：polypharmacy + 認知障礙 → ADE 風險上升

**個人化建議**：advance care planning · start low/go slow · medication review · deprescribing

# 臨床問題

- HF / ACS 團隊越來越常遇到 **嚴重失智 + CV 疾病** 病人
- 大型試驗系統性排除 → **指引無專門建議**
- 核心問題：**「要不要送導管室？」**

> 機會：建立院內 Clinical Pathway

# 預後數據

| 指標 | 數據 |
|------|------|
| 嚴重失智中位存活期 | ~1.3 年 |
| 6 個月死亡率 | ~25% |
| 合併 HF 的 1 年死亡率 | 50–70% |
| HF 病人認知障礙盛行率 | 40–80% |
| ≥65 歲 ACS 住院的失智盛行率 | **5.9%（17:1）** |

[Mitchell *NEJM* 2009](https://doi.org/10.1056/NEJMoa0902234) · [Cannon 2017](https://doi.org/10.1016/j.cardfail.2017.04.007) · [Krishnaswami 2026](https://doi.org/10.7812/TPP/25.159)

# 臨床決策樹（草案）

```text
嚴重失智 + ACS 入院
  ├── STEMI + 不穩定 → 個別化評估，PCI 可考慮
  ├── STEMI + 穩定 + 餘命 <6 月 → 保守 + Goals of Care
  ├── NSTEMI + 高危 (GRACE >140) → 共同決策
  ├── NSTEMI + 低/中危 → 傾向保守
  └── 所有情境 → 入院即啟動 Goals of Care + DNR
```

---

# 嚴重失智 + HF 照護準則

| 面向 | 建議 |
|------|------|
| 治療目標 | 症狀緩解 (喘、水腫) |
| 藥物 | 利尿劑 + 審慎 ACEI/ARB/BB + deprescribing |
| 裝置 | 不新植入 ICD/CRT；既有 ICD 討論去活化 |
| 住院 | 僅延長瀕死則建議居家/機構 |
| DNR/DNI | 早期完成 AD / POLST |
| 安寧 | FAST 7 + HF → 主動轉介 |

---

# 嚴重失智 + ACS 照護準則

| 面向 | 建議 |
|------|------|
| 診斷 | 非典型表現（躁動、意識改變、喘） |
| 侵入性治療 | STEMI 個別化；NSTEMI 傾向保守 |
| 藥物 | 疼痛控制優先；DAPT 衡量出血/跌倒 |
| 不建議 | CABG / IABP / ECMO / MCS |
| Goals of Care | 入院即啟動 |

---

# 失智評估量表（神內專家建議）

> **朱政一醫師建議**：院內 EMR 已有 **CDR / MMSE**（電子表單→失智症評估），不需重複施測 Mini-Cog；**FAST** 為 advanced dementia 首選量表，可預測存活時間。

| 量表 | 用途 |
|------|------|
| **CDR** ⭐ | 院內已建置；CDR 3 = 重度 |
| **MMSE** ⭐ | 比 Mini-Cog 完整 |
| **FAST** ⭐⭐ | Stage 7 = 餘命 ≤6 月 |
| **CFS** | CFS ≥5 Frail；PCI 死亡 ↑6 倍 |

# 家屬溝通

| 階段 | 做法 |
|------|------|
| 入院時 | 確認代理決策人 + 既有 AD |
| 病情說明 | 疾病軌跡：失智末期 → CV 後預後更差 |
| 決策支持 | PDA + 書面 + 充分時間 |
| 情緒支持 | 心理/社工會談；「舒適 ≠ 放棄」 |
| 文件化 | DNR / 維生意願書 / POLST |
