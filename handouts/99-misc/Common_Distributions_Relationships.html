常見機率分佈之間的關係
Relationships Among Common Distributions

一張看似複雜的關係圖，其實只講三件事：
怎麼「加起來」、怎麼「取比值」、以及「數量變大時會變成誰」。

實線 = 變換 / 特例（Transformation / Special case） 虛線 = 極限（Limit，樣本或參數 →∞）

原圖出處：techwith.ram ·　本簡報為教學重製與詳解

導讀

這張圖怎麼讀？兩種箭頭、三條主線

兩種箭頭

實線：一個分佈經由數學運算或設成特例直接變成另一個。例如把很多個相加、取比值、取平方、取對數。關係是「精確」的。

虛線：當樣本數或參數趨近無窮大時，一個分佈的形狀「逼近」另一個。關係是「近似 / 極限」的。

三條貫穿全圖的主線

  • 計數家族：Bernoulli → Binomial → Poisson（成敗與稀有事件）
  • 常態樞紐：中央極限定理讓「很多東西的總和」都趨近常態
  • 等待 / 存活家族：Exponential → Gamma → Weibull（時間到事件發生）

再由常態衍生出統計檢定用的 χ²、t、F —— 這正是你在論文裡天天看到的那組分佈。

核心觀念

整張圖只有三個「動作」在重複

動作一

相加 ∑Xᵢ

獨立同分佈相加 → 常常變成「同一家族的放大版」或趨近常態。
Bernoulli 加成 Binomial；Exponential 加成 Gamma。

動作二

取比值 / 變換

兩個分佈相除、取平方、取對數 → 生出新分佈。
常態相除得 Cauchy；常態平方和得 χ²。

動作三

趨近極限

參數或樣本 →∞ → 形狀逼近另一個分佈。
Binomial、Poisson 在數量大時都趨近常態。

→ / 空白鍵：下一頁　·　O：總覽　·　F：全螢幕
第一部分

計數家族離散 DISCRETE

從「一次成敗」開始，一路長成「多次成敗」「稀有事件計數」。這一族回答的是：在固定條件下，事件會發生幾次？

Bernoulli (p)∑Xᵢ ▸ Binomial (n,p)n→∞ ▸ Poisson (λ)λ→∞ ▸ Normal

臨床對應：單一病人是否發生 MACE（Bernoulli）→ 一組病人的事件人數（Binomial）→ 每月急診 STEMI 到院次數（Poisson）。

計數家族 · 1

Bernoulli → Binomial：把成敗加起來

Bernoulli (p)單次試驗：成功=1、失敗=0
Binomial (n, p)n 次獨立試驗的成功「次數」

直覺：丟一次硬幣是 Bernoulli；丟 n 次、數有幾次正面，就是 Binomial。

實線（特例）：Binomial 設 n = 1 就退回 Bernoulli。

實線（相加）：∑ Xᵢ —— n 個獨立 Bernoulli 相加 = Binomial。

參數意義：期望值 E[X]=np，變異數 Var=np(1−p)。這就是為什麼「事件比例」的標準誤是 √(p(1−p)/n)。

計數家族 · 2

Binomial → Poisson：稀有事件的極限

Binomial (n, p)
Poisson (λ)

直覺：當「試驗次數 n 很大、但每次成功機率 p 很小」，總次數就服從 Poisson。這叫稀有事件定律（law of rare events）。

虛線（極限）：λ = np，n → ∞（p→0）。

Poisson 的特色：只有一個參數 λ，且平均數 = 變異數 = λ。也具可加性：∑Xᵢ 仍是 Poisson（自迴圈箭頭）。

臨床：每 10 萬人年的罕見藥物不良反應、每月導管室緊急到院次數 —— 分母大、單一機率小，就是 Poisson。若資料「變異數 > 平均數」（過度離散），要改用下一頁的 Negative binomial。

計數家族 · 3

Geometric → Negative binomial：等到第幾次才成功

Geometric (p)第一次成功前，失敗了幾次
Negative binomial (n, p)累積到第 n 次成功前的失敗數

直覺：Binomial 固定「次數」數成功；Geometric / NegBinom 反過來，固定「成功數」數要等多久。

實線（相加）：∑ Xᵢ —— n 個獨立 Geometric 相加 = Negative binomial。

虛線（極限）：Negative binomial 在 λ = n(1−p), n → ∞ 時趨近 Poisson。
因此 NegBinom 常被當成「過度離散的 Poisson」來用。

研究應用：住院次數、再入院計數這類「變異大於平均」的計數資料，NegBinom 迴歸比 Poisson 迴歸更合適。

計數家族 · 4

Hypergeometric → Binomial：抽出後放不放回

Hypergeometric (M, N, K)不放回抽樣
Binomial (n, p)放回（或母體極大）

直覺：從 N 個裡有 M 個陽性，抽 K 個看抽到幾個陽性 —— 因為不放回，每抽一次都改變剩下的比例，這是 Hypergeometric。

虛線（極限）：p = M/N, n = K, N → ∞。母體大到「抽走一個幾乎不影響比例」，不放回就≈放回，Hypergeometric → Binomial。

應用：Fisher 精確檢定的核心就是 Hypergeometric；小樣本 2×2 表用它，樣本一大就回到卡方（Binomial/常態近似）。

計數家族 · 5

Beta-binomial 與 Discrete uniform：機率本身也會變動

Beta-binomial (n, α, β)
Discrete uniform

直覺：Binomial 假設成功率 p 固定；但若 p 本身有不確定性（用 Beta 分佈描述），把它混合起來就是 Beta-binomial —— 這是貝氏思維的雛形。

虛線：p = α/(α+β), α+β → ∞（p 幾乎確定）時 → Binomial。

實線（特例）：α = β = 1 時 → Discrete uniform（每個結果等機率）。

串接：Beta-binomial 用到的 Beta 分佈，稍後會在「常態衍生家族」再出現一次 —— 它是連續版的「比例」分佈。

第二部分

常態樞紐與中央極限定理HUB

為什麼常態分佈坐在整張圖的正中央？因為它是大量獨立影響加總後的共同歸宿 —— 這就是中央極限定理（CLT）。

Binomial
μ=np, σ²=np(1−p), n→∞

Poisson
λ=σ², λ→∞

Gamma
r→∞

上面三個離散/偏態分佈，只要「數量或形狀參數 →∞」，虛線全都指向中間的 Normal (μ, σ²)。

常態樞紐 · 1

中央極限定理：為什麼「平均」總是常態

一句話：不論原始資料長什麼樣，只要把夠多的獨立隨機量加起來（或取平均），其分佈就會趨近常態。

Binomial → Normal：μ = np, σ² = np(1−p), n → ∞（De Moivre–Laplace）。

Poisson → Normal：λ = σ², λ → ∞。

實務門檻：Binomial 近似常態常用 np ≥ 5 且 n(1−p) ≥ 5；Poisson 約 λ ≥ 10。

Normal (μ, σ²)

整張圖的樞紐：幾乎所有「總和 / 平均」的極限都在這裡交會。

為什麼臨床重要：樣本平均、迴歸係數、log(OR/HR) 的估計，靠 CLT 才能用常態去算信賴區間與 p 值 —— 即使原始資料不是常態。

常態樞紐 · 2

標準化與對數變換：同一個常態的三種面貌

Normal (μ, σ²)
Normal(μ,σ²) (X−μ)/σ ▸ Normal(0,1)

標準化：Z = (X − μ)/σ 把任何常態壓成標準常態；反向 X = μ + σZ。

Lognormal右偏、只取正值

指數 / 對數：若 X ~ Normal，則 e^X ~ Lognormal；反過來 log(Lognormal) ~ Normal。

臨床對應：檢驗值如 CRP、三酸甘油酯、病毒量、住院天數常呈右偏 —— 取 log 後接近常態，才適用 t 檢定 / 線性迴歸。這也是報告中「幾何平均數」的由來。

第三部分

常態衍生：統計檢定三兄弟χ² · t · F

把「標準常態」拿去平方、相加、相除，就得到假設檢定裡最常見的三個分佈。這一部分是理解 p 值的關鍵。

χ² (ν)

標準常態的平方和

t (ν)

常態 ÷ √(χ²/ν)

F (ν₁, ν₂)

兩個 χ² 的比值

抽樣分佈 · 1

χ²：標準常態的平方和

Chi-squared (ν)ν = 自由度

由常態而來：χ²(ν) = Z₁² + Z₂² + … + Z_ν²，ν 個獨立標準常態的平方和。

可加性：∑Xᵢ —— 兩個 χ² 相加，自由度相加。

與 Gamma 的關係：χ²(ν) = Gamma(r = ν/2, λ = ½) —— χ² 只是 Gamma 的一個特例。

用途：適合度檢定、列聯表獨立性（卡方檢定）、變異數的信賴區間。自由度越大，χ² 越對稱、越像常態（虛線 →Normal）。

抽樣分佈 · 2

t 分佈：把「未知的標準差」考慮進去

Student's t (ν)比常態厚尾

定義：t = Z / √(χ²(ν)/ν) —— 分子是標準常態，分母是「用樣本估計的標準差」。因為分母也有誤差，t 比常態尾巴更厚。

ν → ∞：自由度越大，估計越準，t → Normal(0,1)。

ν = 1：退化成 Cauchy（厚尾到連平均數都不存在）。

臨床：小樣本比較兩組平均（t 檢定）、迴歸係數檢定都用 t。樣本一大（>30~50），t 與 z 幾乎沒差。

抽樣分佈 · 3

F 分佈：兩個變異數的比值

F (ν₁, ν₂)

定義：F = (χ²₁/ν₁) / (χ²₂/ν₂) —— 兩個「標準化後的變異數」相除。

與 t 的關係：t(ν)² = F(1, ν)。t 檢定平方後就是 F 檢定。

ν₂ → ∞：ν₁·F → χ²(ν₁)。

用途：ANOVA（比較多組平均，其實是在比「組間 vs 組內」變異數）、迴歸整體顯著性檢定。這解釋了為何 ANOVA 的統計量叫 F 值。

抽樣分佈 · 4

Cauchy：反例警示 —— 平均數不會收斂

Cauchy= t(ν=1)

兩個常態相除：X₁ / X₂（兩個獨立標準常態的比值）= Cauchy。

倒數不變：1/X 仍是 Cauchy；t(1) 也是 Cauchy。

為什麼重要：Cauchy 尾巴太厚，期望值與變異數都不存在。所以它的樣本平均不會因為 n 變大而收斂 —— ∑Xᵢ 的平均還是 Cauchy。

教學價值：它是「中央極限定理不成立」的經典反例，提醒我們 CLT 需要有限變異數這個前提。比值型指標（如某些劑量比、風險比在極端情形）要小心厚尾。

第四部分

等待 / 存活家族TIME-TO-EVENT

這一族回答：「到事件發生要等多久？」 —— 正是存活分析的數學核心。

Exponential (λ)∑Xᵢ ▸ Gamma (r, λ) 　γ 變換 ▸ Weibull (γ, λ)

Exponential 假設「風險率固定」；Weibull 允許風險隨時間上升或下降（老化 vs 早夭）—— 這就是 Cox 迴歸之外最常用的參數存活模型。

等待 / 存活 · 1

Exponential → Gamma：等第 1 次 vs 等第 r 次

Exponential (λ)到「下一次」事件的等待時間
Gamma (r, λ)到「第 r 次」事件的等待時間

直覺：Poisson 數「單位時間內幾次」；Exponential 是它的另一面 —— 「兩次事件之間隔多久」。

相加：∑ Xᵢ —— r 個獨立 Exponential 相加 = Gamma；r = 1 時 Gamma 退回 Exponential。

無記憶性：Exponential 的 min Xᵢ 仍是 Exponential（自迴圈）—— 「已經等了多久」不影響「還要再等多久」。

r → ∞：Gamma 趨近 Normal（μ=rλ, σ²=rλ²）。

等待 / 存活 · 2

Weibull 與 Double exponential：放寬與對稱化

Weibull (γ, λ)

γ 變換：Exponential 取 X^{1/γ} 型變換 → Weibull；γ = 1 時就是 Exponential。

γ>1：風險隨時間上升（老化、磨損）；γ<1：風險遞減（術後早期高危、之後趨穩）。存活分析首選參數模型。

Double exponential（Laplace）

相減：X₁ − X₂（兩個獨立 Exponential 相減）= Laplace（對稱雙尾）。

取絕對值：|Laplace| = Exponential。

Laplace 是 L1 正則化（LASSO）的貝氏先驗，尖峰厚尾、能把係數壓到 0。

等待 / 存活 · 3

Gamma → Beta → Uniform：把兩個等待時間「正規化」

Beta (α, β)介於 0~1 的「比例」
Uniform (0, 1)

Gamma → Beta：X₁ / (X₁ + X₂)，兩個 Gamma 的「佔比」= Beta(α, β)。Beta 天生活在 0~1 之間，是描述機率 / 比例的分佈。

Beta → Uniform：α = β = 1 時 Beta 變成 Uniform(0,1)（完全無資訊）。

Uniform → Exponential：−ln(U)/λ ~ Exponential（反函數取樣法）；反向 e^{−λX} 把 Exponential 映回 Uniform。

貝氏收尾：Beta 是 Binomial 的共軛先驗 —— 這把我們帶回第一部分的 Beta-binomial。整張圖在此閉環。
